Tibi

它怎么对待你的数据、怎么称呼你，以及能不能被别的工具调用。它会做的事在下一组"技能"里。
Tibi 修改学习数据时
例如标记生词、加入生词本、导入文章、写入记忆。所有操作都可撤销
Tibi 怎么称呼你，用什么语言聊
Tibi 自己的名字不改——它就是这只藏狐
允许其他 AI 工具使用 Tibi（MCP）
开启后可在 Codex、Claude Code 等终端里查词、出题、导入文章；它们的写操作同样按上面的权限先问你，记录在任务中心
接入配置
{"mcpServers":{"tibi":{"command":"tibi","args":["mcp"]}}}

Tibi 的技能

Tibi 会做的事。平时不用管；想让某项技能更合你心意，可以换模型档或加一句指令。Tibi 只用它自己的能力（查词、标词、导入、出题…），不会运行任意代码。在首页输入 / 可以直接选。
例行任务 · Tibi 按时自动做的事，结果放在首页和任务中心
