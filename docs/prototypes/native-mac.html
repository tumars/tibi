部位现在原生化靠什么实现
窗口与标题栏没有系统标题栏，整块灰底里放一张 16px 圆角白卡红绿灯嵌在侧栏里，侧栏延伸到窗口顶；内容区平铺、不再有"卡片"Tauri titleBarStyle: Overlay + hiddenTitle，红绿灯位置在 Rust 里设
侧栏材质与底色同色的实心灰半透明毛玻璃，透出桌面壁纸（这里用 CSS 模拟）window-vibrancy 的 Sidebar 材质，网页背景透明；macOS 26 可换 Liquid Glass
字体字号Geist + 普惠体，14px系统字体（SF Pro + 苹方），13px 正文、11px 小字，粗细更稳-apple-system 字体栈；Windows 再回落到 Segoe UI / 微软雅黑
控件胶囊、大圆角、实心墨色主按钮24px 高、6px 圆角、极淡的描边与投影，主按钮用系统蓝渐变自己的 token；无现成的 mac 皮肤库值得用
选中与强调蓝色浅底 + 蓝字侧栏选中行是实心强调色 + 白字（失焦变灰）。不跟随系统强调色（E4 不采用）：仍用品牌靛蓝，和手机版、logo 一致自己的 token（--accent）
分割线1px，7% 黑0.5px 发丝线（视网膜屏下真是半像素）box-shadow: inset 0 -.5px，不用 border
菜单与右键HTML 画的菜单系统原生菜单与右键菜单Tauri 2 Menu API（Menu.popup）

强调色统一用品牌靛蓝（AI 标识 ✦、进度、选中、焦点、默认按钮），不跟随系统强调色（E4 不采用）。藏狐橙不变。
