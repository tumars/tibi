# 05 调研：词光（Word Atlas）的复习设计，对 Tibi 的参考

> 2026-10-30。对象：[designfuchen/word-atlas](https://github.com/designfuchen/word-atlas)（代码 MIT，词库与插画 CC BY 4.0）与在线版 [0xlei.tech/words](https://0xlei.tech/words/)（练习页 `#/practice`、学习页 `#/learn`）。读了仓库的 `docs/learning-model.md`、`src/store/session.ts`、`src/store/srs.ts`、`src/pages/Learn.tsx`、`Practice.tsx`、`Today.tsx`，并在浏览器里走完一轮学习（5 个新词 + 回忆 + 故意答错）。在线版比仓库多了"今日阅读""易混词辨析""同义替换""考试日期"等功能。建议的决策 G1–G8 **已于 2026-10-30 全部采用**，落在 `00-concept-design.md` §3.3、`01-database.md`（review_sessions、practice_logs）、`06-interface.md`（review.*、practice.*）与复习原型。

## 1. 它的理念，一句话

**用户只管答题，评分交给系统。** 每张卡都是有标准答案的客观题（四选一、看图补句、听音辨词、拼写），答完系统根据"对不对 + 用了多久 + 有没有用提示"自动换算成 FSRS 的四档评分；用户全程看不到"忘了 / 模糊 / 记得 / 轻松"，也看不到间隔。复习页只有一个动作：答题 → 继续。

围绕这一点，它还做了几件互相配合的事：

| 机制 | 做法（来自代码） |
|---|---|
| 自动评分 | 答错 → Again；答对但慢（选择题 > 9 秒、拼写 > 20 秒）或用了提示 → Hard；答对 → Good；拼写又快又对（< 6 秒）→ Easy |
| 只有第一次作答算数 | 每个词在一轮里只有首次作答更新 FSRS 和正确率；之后的重练不评分 |
| 答错就换个题型再练 | 答错的词插到 4 张之后，换一种题型再出一次，最多两次，标"错词再练"；不计分 |
| 新词先见后练 | 新词每 5 个一组：先逐个"初次见面"（插画、释义、例句、发音，按 Enter 继续），再把这 5 个打乱顺序用题目回忆 |
| 先复习后新词 | 注意力最好的时候先清到期，再学新的；"今日旅程：复习 n · 新词 n · 约 n 分钟" |
| 题型随记忆强度变化 | 稳定度 < 2 天：选义 / 看图补句 / 听音；稳定度 ≥ 4 天才出拼写 |
| 干扰项要"像" | 选义题的干扰项同词性、同难度、中文不重叠；听音 / 补句题的干扰项同首字母、长度相近 |
| 提示逐字母给 | 拼写题"提示字母"一次露一个，用了提示最多算 Hard |
| 旅程可续 | 中途退出，进度保存，首页显示"旅程进行中，还剩 n 步" |
| 完成页 | 首次正确率圆环、本轮所有词（错的标红）、"再练 n 个错词"（不计分）、分享成绩卡 |
| 练习与记忆分开 | "练习"页的单词打字、例句打字、听写只练输出，**不改动记忆状态**，成绩（WPM、准确率）单独记录；词来自最近学过 / 错词本 / 收藏 / 学习路线 |
| 用阅读巩固 | 在线版首页"今日阅读"：一篇约 1 分钟的分级短文，含 10 个还没学的重点词 |
| "已掌握"的定义 | FSRS 复习状态且稳定度 ≥ 21 天（三周后仍有 90% 把握记得） |

体验上的感受：一张卡一个决定，节奏很快；答错时的反馈是"这次没答对，看看词义再试"，不责备；错词几张之后换个样子回来，像有人陪练。

## 2. 和 Tibi 现在的复习对照

| 方面 | Tibi（00 §3.3） | 词光 | 判断 |
|---|---|---|---|
| 评分 | 每张卡用户自己点四档，按钮下显示间隔；输入题会预选建议评分 | 系统自动评分，用户看不到四档与间隔 | **最值得借鉴**。自评是 Anki 的老问题：每张卡多一次决定、评分标准因人而异、用户容易"手松"。Tibi 的填空、听写、拼写本来就有标准答案，没有理由再让用户自评 |
| 低熟练度的题 | 识别：看原句 → 心里回答 → 显示答案 → 自评 | 选义四选一、看图补句、听音辨词 | Tibi 的识别题完全靠自觉，没有客观信号。加一个四选一的"选义"可以让最初几次复习也有客观对错 |
| 答错之后 | 本轮结束前以识别题再出现一次 | 4 张之后换题型再练，最多两次，不计分 | 词光的更好：间隔短、换题型、不污染 FSRS 记录 |
| 新卡 | 直接进识别题 | 先见（5 个一组）再练 | 部分适用。Tibi 的新词大多是读文章时标的，用户已经在语境里见过；但从词表导入、"添加"的词没见过，需要"初见" |
| 提示 | 填空题始终给中文提示 + 首字母 | 逐字母给，用了提示最多 Hard | 借鉴：提示应该是用户主动要的，并进入评分 |
| 用时 | API 已有 `duration_ms`，没用于评分 | 慢 = Hard | 借鉴 |
| 中途退出 | 没有设计 | 进度保存可续 | 借鉴，成本低 |
| 完成页 | 数量、记得比例、用时、分布、熟练度变化 | 首次正确率、词表、再练错词 | 借鉴"再练错词"；"首次正确率"比"记得或轻松的比例"更诚实 |
| 不计分的练习 | 只有 `review.quiz` / `create_quiz`（临时练习不影响排期），没有界面 | 独立"练习"页：打字、听写、易混词辨析 | 部分借鉴：Tibi 最有特色的是**用户自己读过的句子**，听写原句比听写词库例句更有价值 |
| 复习后再读 | 有"读一篇新文章"按钮 | "今日阅读"：含今天要学的词的短文 | 借鉴，而且这是 Tibi 的主场：让选文技能找、或让 Tibi 写一篇包含今天复习词的短文，闭合"读 → 复习 → 读"的环 |
| 掌握 | 稳定度约 60 天才可能升到"掌握"；六档熟练度 | 稳定度 ≥ 21 天 | 不改。Tibi 的六档熟练度同时服务阅读着色，标准可以更严 |
| 插画、星图、环境声、音效 | 无 | 每词一幅画、WebGL 星图、6 段环境声、答题音效 | 不借。Tibi 的词来自任意文章，无法预先配图；"安静的 AI 工作台"不适合背景音乐。最多加可选的轻微答题音效，默认关 |
| 固定词表 / 学习路线 | 无（词来自阅读） | 7,298 个雅思词，按 CEFR 排路线 | 不借路线；但词库可作为数据源（§4） |

## 3. 建议（G 组：复习）

| 编号 | 建议 | 说明 |
|---|---|---|
| **G1** | **客观题自动评分**：填空、听写、拼写、选义答完即判，系统按"对错 + 用时 + 是否用提示 + 拼写距离"给出评分，动作区只剩一个"继续"（Enter）；评分以一行小字显示（"记得 · 3 天后再见"），点它或按 1–4 可以改 | 只有"识别"题保留自评。评分规则：错 → 忘了；对但慢 / 用了提示 / 拼写差一个字母 → 模糊；对 → 记得；拼写又快又对 → 轻松。阈值按题型，正式版用个人中位用时校准 |
| **G2** | **新增"选义"题**（四选一），和"识别"一起用于生词 / 见过 | 干扰项优先取：同一篇文章里的其他生词、生词本里同词性同难度的词、易混词（affect / effect）。这样干扰项本身也是一次复习 |
| **G3** | **只有首次作答算数**；答错的词在 3–4 张之后换一种题型再出现（最多两次），标"再见一面"，不计分、不改 FSRS | 取代现在"本轮结束前以识别题再出现一次"。FSRS 的短期学习步骤（1 分钟 / 10 分钟）照常由 ts-fsrs 管 |
| **G4** | **没见过的新词先"初见"**：从词表导入、"添加"、"已知词表以外的推荐词"进入复习时，5 个一组先看词卡（原句或词典例句、释义、发音，Enter 继续），再打乱回忆；读文章时标的词跳过初见 | 读过的词已经在语境里见过，再看一遍是浪费 |
| **G5** | **提示由用户主动要**：填空题默认只给中文提示，首字母改为"提示"按钮（H），一次露一个字母；用了提示最多"模糊" | |
| **G6** | **复习可续**：中途离开保存进度；首页"待复习"卡片和复习页显示"上次还剩 n 张，接着复习" | |
| **G7** | **完成页加两件事**："再练 n 个错词"（不计分，调用 `review.quiz`）；"读一篇用到这些词的短文"（选文技能先找；找不到时由 Tibi 写一篇 300 词以内、生词率 ≤ 5% 的短文，标明是生成的）。正确率改为"首次正确率" | 第二件是 Tibi 能做而词光做不到的：短文里的词全是用户自己的生词 |
| **G8** | **不计分的练习**（排在 M5 之后）：复习页加"练习"分段——听写原句（用户读过的句子，整句）、例句打字、易混词辨析；只记准确率与用时，不改记忆状态 | 不做单独的导航项，避免功能膨胀 |

## 4. 词库数据可以用吗

词光的词库（7,298 词，CEFR A1–C2，19 个话题，每词两条例句带中译、搭配、词族、易混提示 `tip`）按 CC BY 4.0 开放，署名即可商用。对 Tibi 有用的字段：

- `tip`（如"principle 是原则；principal 是校长"）→ 复习答案区的"易混提示"，以及 G2 的易混干扰项；
- `col`（常用搭配）→ 词卡与造句题的目标搭配；
- `cefr` → 补 ECDICT 没有的 CEFR 等级，供难度估算。

限制：内容由生成式 AI 产出、**尚未逐条人工审校**（README 自述），只收雅思词。建议作为 ECDICT 之外的可选补充数据（`dict.db` 的一张附表），界面上标出处；插画与录音不用。是否引入放到 M3 再定。

## 5. 对接口与数据的影响（已落实，以 06 / 01 为准）

- `review.answer` 改为由 Core 判分：参数从 `{ card_id, rating, card_type, ... }` 改为 `{ card_id, card_type, answer: { typed?: string; choice?: Id; self_rating?: Rating }, hints: number, duration_ms, attempt: 'first' | 'retry' }`，返回里带 `rating`（系统给的）与 `override_allowed`；新增 `review.override({ card_id, rating })`。
- `review.queue` 返回的每项多 `intro: boolean`（是否先初见）与选义题的 `options`。
- `review_logs` 加 `auto_graded`、`hints`、`attempt`；重练（retry）不写 `review_logs`，只写会话统计。
- 新增 `review_sessions` 表（或放 `settings` 键）保存进行中的会话，支持 G6。
- G7 的"写一篇短文"复用选文技能（scout）+ 主对话写作，不新增能力。
