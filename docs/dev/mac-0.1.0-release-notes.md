# Tibi 0.1.0 · 首个 Mac 版本

Tibi（提比）是一款本地优先的英语阅读与学习工具。

- 导入英文文章和书籍，在阅读中查词、积累生词并复习。
- 内置离线词典和图文示例书；阅读、查词与基础学习无需配置模型。
- 配置自己的模型服务后，可使用 AI 对话、讲解等功能。
- 数据保存在本机，支持备份和应用内更新。

## 安装

本次提供 **Apple Silicon（M1 及更新芯片）** 版本，要求 macOS 13 或更高版本。下载 `Tibi_0.1.0_aarch64.dmg`，打开后将 Tibi 拖入“应用程序”。Intel Mac 安装包不在本次首发范围内。

`.app.tar.gz` 和 `.sig` 是自动更新使用的文件，手动安装请选择 `.dmg`。

AI 模型服务需要自行配置，可能产生服务商费用；AI 朗读首次使用需要下载模型。问题反馈请通过应用设置中的“反馈与建议”或仓库 Issues。
