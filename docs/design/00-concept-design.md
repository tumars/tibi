> 项目名：**Tibi（缇比）**，来自吉祥物藏狐（Tibetan fox）。吉祥物、产品与 AI 助手同名同一个角色（2026-10-29 确认，原暂定名 LexiRead）。

## 1. 产品定位

**一句话**：一个本地优先、AI 原生的英语阅读学习工具——**读你感兴趣的文章，顺便把英语学会**。

**首发人群**（2026-10-31 确认）：读英文技术文档和博客的程序员。内置示例、默认类型和剪藏插件都先按他们做。

**长期目标用户**：
- 有一定基础（约 CET-4 及以上 / 词汇量 3000+）、希望通过真实英文材料提升阅读与词汇的中文母语学习者。
- 程序员、科研人员、留学准备者等"本来就要读英文"的人群。
- 阅读材料覆盖**技术文档、新闻、小说**及各类英文文章（见 3.1 内容类型）。

**不做什么**（至少 v1 不做）：
- 不做零基础课程、语法课体系。
- 不做内容平台（不提供文章，用户自己导入）。
- 不做社交、排行榜。
- 不做账号体系 / 云服务（数据本地）。手机与电脑之间的同步（M7）走局域网或用户自己的云盘文件夹，不经过我们的服务器。
- 不做跟打练习、用户自定义技能、定时的例行任务（2026-10-31 已砍，见 [§6](#6-版本规划建议)）。

**怎么持续**（R12，2026-10-31 确认）：**纯开源 + 自带 Key**。用户用自己的模型 API Key（默认 DeepSeek），花费直接付给模型服务商；我们不做托管服务、不收订阅费、不经手用户数据。项目靠开源社区维护。

**差异化**：

| | LingQ | Lute / LinguaCafe | 背单词 App | **Tibi** |
|---|---|---|---|---|
| 自选素材 | ✅ | ✅ | ❌ | ✅ |
| 视觉 / 阅读体验 | 一般 | 弱 | 好 | **目标：Readwise 级别** |
| 安装门槛 | 云端 | Python/Docker | App | **桌面安装包** |
| AI 原生 | 后加 | ❌ | 部分 | ✅ 导入即分析 + 常驻助手（有记忆） |
| 可被本地 AI 工具调用 | ❌ | ❌ | ❌ | ✅ 通过 MCP：在 Codex / Claude Code 等终端里直接用 Tibi 的能力 |
| 数据归属 | 云端 | 本地 | 云端 | **本地 SQLite** |
| 语境复习 | 部分 | 部分 | 部分 | ✅ 例句来自自己读过的文章 |

## 2. 核心学习闭环

```
   ┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────┐
   │ 导入文章  │ →  │ 自动分析      │ →  │ 沉浸阅读      │ →  │ 间隔复习  │
   │ 文件/文字 │    │ 识别·分级·    │    │ 着色·查词·    │    │ FSRS +   │
   │ 图片/网址 │    │ 预标注·总结   │    │ 标记·朗读     │    │ 语境卡片  │
   └──────────┘    └──────────────┘    └──────────────┘    └────┬─────┘
        ▲                                                       │
        └───────────── 学习建议 / 推荐复读 / 词汇量成长 ◀─────────┘
```

每读一篇文章，用户的「已知词库」就更准确一点 → 下一篇文章的预标注、难度评估、学习建议就更个性化。**已知词库是整个系统的核心资产。**

## 3. 功能模块

### 3.1 文章导入（Import）

| 输入方式 | 处理 |
|---|---|
| 粘贴文字 | 直接进入流水线 |
| 网址 | 抓取 → 正文提取（Defuddle）→ Markdown，保留标题、作者、封面图、原文链接 |
| 文件 | TXT / Markdown / PDF / EPUB / DOCX；扫描版 PDF 走 OCR |
| 图片 | 单张或多张（拍书页）→ OCR → 可选 AI 清洗 → 合并为一篇 |
| 剪藏插件 | 浏览器里点"发送到 Tibi"，等同于给一个网址（见本节末尾） |

**三个互相独立的维度**（D10）。原先的"技术文档 / 新闻 / 小说"把内容形态和处理策略混在一起，用户的材料（论文、博客、演讲稿、字幕）塞不进去，一本技术书也只能二选一，所以拆开：

| 维度 | 取值 | 谁定 | 用来做什么 |
|---|---|---|---|
| **形态**（kind） | `article` 文章 / `book` 书 | 导入时由来源决定（EPUB、多章 PDF、目录型网页 → 书），不可改 | 书有章节：书架上一本书一张卡、阅读器左栏目录、进度按"本章 + 全书"两级、按章懒处理、书级的人物表与前情提要 |
| **类型**（genre） | `tech` 技术 / `news` 新闻 / `lit` 文学 / `academic` 学术 / `general` 一般 | 自动识别，可在书架卡片菜单里改 | 只决定**处理策略**：分词与着色规则、专有名词是否忽略、AI 产出什么（见下表）。界面上退成卡片上的一枚小标签 |
| **标签**（tags） | 自由文本，不分层级，如 Rust、气候、福尔摩斯、雅思备考 | 用户的；导入完成时 Tibi 从关键词建议 1–3 个，点一下采纳 | 书架筛选（可多选）、"找文章"的兴趣画像、生词本与出题按标签筛（"只练 Rust 相关的词"）、搜索 |

**类型 → 处理策略**：

| 类型 | 典型来源 | 特殊处理 |
|---|---|---|
| **技术** | 官方文档、博客、技术书 | 代码块 / 行内代码 / URL **不参与分词与着色**，代码块语法高亮；专有名词与 API 名默认忽略；AI 产出**领域术语表**（如 latency、idempotent），术语可单独归类 |
| **新闻** | 网址 | 保留发布时间、来源；人名地名等专有名词默认忽略；AI 产出背景知识简介 |
| **文学** | 小说、短篇、EPUB | AI 产出人物表、章节摘要、"前情提要"（书）；文学 / 低频词多，预标注阈值可适度放宽，允许"只标高频生词"模式；标出熟词僻义 |
| **学术** | 论文 PDF、arXiv | 公式、引用、图表题注不参与着色；AI 产出摘要式总结与术语表 |
| **一般** | 文字、图片、其他网址 | 默认策略 |

导入后进入**处理流水线**（后台任务，界面显示进度，可先读后分析）：

1. **提取**：得到干净的 Markdown 正文。
2. **结构化**：分段 → 分句 → 分词 → 词形还原（went → go）。
3. **本地分析**（毫秒级，零成本）：
   - 与用户已知词库比对，得出每个词的状态。
   - 计算**生词率 / 覆盖率**、预估 CEFR 级别、预估阅读时长。
4. **自动预标注**（本地规则为主）：对用户从未遇到过的词，根据「用户词汇量画像 + 词频 + 考试标签」判断"大概率已知 / 大概率生词"。
   - **中间带规则**（全文只在这里定义，§3.9 引用）：估算词汇量为 N 时，词频前 N 的词默认视为已知，N 到 N+3000 标记为"可能不认识"，N+3000 以上默认视为生词。例：N = 6000 时，前 6000 已知，6000–9000 可能不认识，9000 以上生词。
5. **AI 分析**（异步，结果缓存入库）：
   - 文章总结（中文，3–5 句）+ 主旨大意 + 关键词。
   - 值得学习的**短语/搭配**（3–10 个，含语境释义）。
   - **长难句**（2–5 句）结构拆解。
   - **熟词僻义**：标出常见词的少见义项（如小说中 let = 出租、single = 单身的），在词卡中提示。
   - **学习建议**：基于本篇生词率与用户水平，例如"本文生词率 6%，超出学习区（2–5%），建议先看总结再读"、"重点关注 X 类词"。

> ✅ **D1（已确认）**："可能不认识"的中间地带词使用第三种轻量视觉状态（虚线下划线），用户阅读时一键确认为生词或已知（已知记为 97，见 §3.2）。

**剪藏插件**（R4，2026-10-31 确认，M1）：只有"发送到 Tibi"一个动作，不在网页上标词。

- **扩展**：只用 `activeTab` 权限取当前标签页的 URL（只发 http(s)），通过深链 `tibi://import?url=…` 打开 Tibi，应用没开时由系统拉起。不用本地服务和 native messaging，不读页面内容，也不登录。
- **Tibi**：深链算外部触发。按 [05 §8](05-agent-architecture.md#8-权限审批与安全) 校验 URL，弹出确认卡（显示站点和网址）；用户确认后才抓取，取消则什么都不留。
- **失败**：需要登录的页面抓不到正文时走失败态，提示打开页面复制正文、粘贴到 Tibi。

### 3.2 沉浸式阅读面板（Reader）——核心界面

> 可交互原型：[`docs/prototypes/reader.html`](../prototypes/reader.html)（浏览器直接打开）。原型中的交互细节以本节为准，原型仅用于验证观感。

**布局（桌面端，v2）**：

```
┌────┬───────────────────────────────────────────────────────┬──────────────────┐
│ L  │ 首页 / Understanding Ownership   译文 行间释义 │ ▶朗读 Aa │ 总结 生词 ✦Tibi │（按需出现）│
│ ⌂  │                                                       │ [总结|生词|✦Tibi]│
│ ▥  │        正文（居中 ~680px，Charter 衬线）                 │                  │
│ ▢  │   Remote work has become ▔ubiquitous▔ in ┌───────────┐ │  AI 总结 / 本篇   │
│ ↻  │   the tech industry, and many companies  │ 词卡浮层   │ │  生词 / 对话       │
│    │   ‹grappling with› the long-term …       │ 贴着单词   │ │                  │
│    │                                          └───────────┘ │                  │
│ ◔  │ ▓▓▓░░ 45%  生词 23 · 学习中 8          生词率 4.2% 学习区│                  │
└────┴───────────────────────────────────────────────────────┴──────────────────┘
 左栏默认折叠为图标栏（⌘\ 展开，展开后显示书架与目录）
```

**交互**：

| 操作 | 行为 |
|---|---|
| 单击单词 | 生词自动变成"见过"并建卡（规则见下方 R5）。**词卡以浮层贴着单词出现**（宽屏放在正文右侧页边，与单词同高；空间不足时放在单词下方或上方；窄屏为底部抽屉）：音标、发音、**AI 语境释义**、词典释义、熟练度；"所在句子、翻译与解析"默认折叠。点空白处或 `Esc` 关闭 |
| 选中多个词 | 弹出"标记为短语"；之后所有文章中自动识别该短语 |
| 点击句末/句子菜单 | 句子翻译、长难句拆解、朗读本句、循环播放 |
| 快捷键 | `0–4` 设熟练度（生词 → 熟悉）、`K` 掌握、`I` 忽略、`J` / `→` 下一个生词、`P` 播放 / 暂停、`T` 译文、`G` 行间释义、`Esc` 关闭 |
| **读完本页/本篇** | "将剩余未处理的生词全部标为已知"：只把 status = 0 的词设为 97（标为已知），**不动待确认词（99）**，带撤销（LingQ 经验：维护已知词库的关键动作） |
| 回顾本篇重点 | 读完后从头依次用细描边点亮仍在学习的短语和生词（CSS 动画），帮助回顾 |
| 主题 | 亮色 / 暗色 / 护眼（米色）；字号、行高、字体可调；**版心**窄 / 标准 / 宽（600 / 680 / 780px，约 60–75 字符一行）|
| **专注模式**（`F`） | 顶栏、底栏、左栏淡出，只留正文；鼠标移到上下边缘时短暂露出工具栏，`Esc` 或再按 `F` 退出。阅读设置里也有开关 |
| 继续上次 | 打开有进度的文章时，底部出现"上次读到 45% · 继续"胶囊，8 秒后自动隐藏；点"继续"滚到上次位置 |
| 辅助程度 | 可切换"着色强度"：全部显示 / 只显示生词 / 纯净阅读 |
| **标注说明** | 底栏的"生词 N · 学习中 N · 待确认 N"带对应色块，点它（或 `?`）弹出标注说明：每种标注给一个真实样子的例词 + 一句话（生词 / 学习中四档 / 待确认 / 短语 / 选中），以及"没标注的词 = 已知、代码和专有名词不参与"；`Esc` 或点外面关闭 |
| **译文**开关（`T`） | 在每段原文下方显示中文译文（段落内各句翻译合并），默认关闭 |
| **行间释义**开关（`G`） | 在生词、学习中的词、学习中的短语上方以小字显示简短中文释义（类似注音的位置），默认关闭；释义来自词典短释义或 AI 语境释义 |

**右侧面板按需出现**（v2）：顶栏的"总结 / 生词 / ✦ Tibi"三个按钮**就是页签**：点一个打开右侧抽屉并高亮，点另一个切换，再点当前这个或 `Esc` 关闭，正文回到全宽。抽屉头部不再重复一组页签，只放当前页签的标题和一个专属动作（总结 → 重新生成；生词 → 剩余全部标为已知；Tibi → 新对话）加关闭按钮。**总结**：AI 总结、难度、术语表 / 背景知识 / 人物表、值得学的短语、长难句、学习建议；**生词**：本篇生词、学习中、待确认列表；**✦ Tibi**：常驻助手（见 3.10）。

书（kind = book）在左栏（展开时）显示**章节目录**，进度按"本章 + 全书"两级显示；"继续阅读"直接跳到上次的章节和句子。章节不单独出现在书架和"最近"里。

**词卡信息顺序**（原型验证）：词头 + 音标 + 柯林斯星级 + 考试标签 → 待确认提示（仅 99 状态）→ 所属短语 → **AI 语境释义** → 词典释义（中文，英英可展开）→ 所在句子（折叠：翻译 / 请 Tibi 解析 / 朗读这句）→ 熟练度六档 + 忽略 + 生词本 + 遇见次数。

**窄屏**：左栏收进菜单按钮；词卡与右侧面板都改为底部抽屉；顶栏只保留译文、行间释义、阅读设置与 Tibi。

> ✅ **D2（已确认，2026-10-31 补充 R5）**：数据模型采用六档（0–5）+ 三个特殊状态（97 标为已知、98 忽略、99 待确认）；UI 默认只突出 2–3 种颜色。**界面上不显示数字**，用"熟练度"名称（2026-10-29 调整）：
>
> | 值 | 名称 | 含义 |
> |---|---|---|
> | 0 | 生词 | 完全不认识 |
> | 1 | 见过 | 有印象，但想不起意思 |
> | 2 | 眼熟 | 结合上下文能猜出大概意思 |
> | 3 | 认得 | 读到时能理解，自己还不会用 |
> | 4 | 熟悉 | 基本掌握，偶尔还会犹豫 |
> | 5 | 掌握 | 已经会了，不再标注 |
> | 97 | 标为已知 | 批量标记的结果：不建卡、不进复习，计入已知词总数，**不等于掌握** |
> | 98 | 忽略 | 专有名词等，不标注、不计入 |
> | 99 | 待确认 | 中间带的词，等用户在词卡上确认 |

> ✅ **R5（2026-10-31 确认）标记规则**：
>
> - **点词**（阅读器调用 `terms.lookup`）：status = 0 的词（含规则判为生词、还没有 `terms` 行的词）自动设为 1（见过）并建卡。受每日新卡上限（默认 20）约束，超出的排队到后面几天。不提供撤销，词卡上可改状态或忽略。
> - 其他状态点开不变：待确认词（99）仍由用户在词卡上确认，确认为已知记 97；规则判为已知的词点开不写入。⌘K 查词典和 MCP `lookup_word` 只读，不改状态。
> - **批量**（`sections.finish` 的 `mark_rest_known`、"翻页标为已知"）：只把 status = 0 的词设为 97，不动 99，也不设为 5。稳定性约 60 天才可能升到"掌握"的规则不变（§3.3）。

### 3.3 生词本与每日练习（Vocabulary & Review）

**生词本**（可交互原型：[`docs/prototypes/words.html`](../prototypes/words.html)；2026-10-30 按业界调研复审，见决策 D11）。下面是完整版，排在 M3；M1 只做基础生词本：列表、搜索、详情与原句、改状态。
- 单词与短语统一管理；每个条目可关联**多个语境**（不同文章中的原句），这是复习卡片的素材来源。**词族合并**：同一原形的词形（verify / verifies / verified）是一条记录，遇见次数与复习合并计算，列表上标"+n 种词形"，详情里可见全部词形。
- **左栏视图**（取代"来源文章"列表，借鉴 Anki 的侧栏与 LingQ 的状态筛选）：全部、今天到期、逾期（红色计数）、本周新增；"值得看看"——难词（复习忘了 3 次以上）、遇见多但没进步、很久没遇见、待确认；"不在复习里"——已忽略、标为已知、已掌握。后三类默认不混在"全部"里，但各有去处、可恢复。进入"难词 / 没进步 / 很久没遇见"视图时顶部一句说明 + 一个动作（先复习这些 / 让 Tibi 找文章）。
- **页头**：当前视图名 + 一行概要（本视图数量、在学的单词 / 短语数、本周新增、今天要复习）；"添加"（输入一个词或粘贴一列，每行一个、可带释义；没有原句的词先用词典例句做卡）、"导入 / 导出"（导入 CSV / 纯文本、Anki 卡组、**已知词表**〔直接标为已知（97），解决冷启动〕；导出 CSV / Anki / 纯文本；Anki 导出的时机待决，§6 排在"后续"，见 [`DECISIONS.md`](../DECISIONS.md#待决定)）、"开始复习 · N"。
- **熟练度分布条**：生词 → 掌握六段，按数量占比，点击某段即按该熟练度筛选（点"掌握"段进入已掌握视图）。
- **筛选与排序**：搜索（单词、词形、释义、原句，按 `/` 聚焦）、单词 / 短语、来源文章；筛选行下面一排**标签胶囊**（与书架页同一组件：带计数、可多选、同时满足、"清除"；词继承来源文章的标签，计数只统计当前视图；从书架页某个标签进来时自动选中）；"原句"开关——开着时每行释义下面显示一句最适合做卡的原句；"列"菜单——勾选音标 / 词频星级 / 考试标签 / 标签 / 遇见 / 记得率 / 下次复习，偏好本机记住；排序：下次复习 / 最近加入 / 遇见次数 / 字母 / 熟练度 / 词频。列表变窄（右侧抽屉打开）时次要列自动收起，勾选不变。
- **列表**：行高 50px；单词（音标、词形数、难词标记"难"）、释义（可带原句行）、熟练度、遇见次数与篇数、下次复习（今天 / 明天 / N 天后 / 逾期 N 天）；悬停时行尾出现发音 / 问 Tibi / "…"菜单（难词多三项：让 Tibi 讲讲、换一种题型、暂停复习 2 周；其余：打开详情、标为掌握、忽略、移出）。勾选后出现批量操作条：设为熟练度、忽略、导出所选、移出（均可撤销）。词条不单独打标签，标签继承来源文章（01 §2）。
- **键盘**（与阅读器一致）：`J` / `K` 或方向键上下移动，`空格` 勾选，`Enter` 开详情，`0–5` 设熟练度，`I` 忽略，`P` 发音，`/` 搜索，`Esc` 关闭。
- **右侧抽屉"详情"**（点选词条时打开，头部有上一个 / 下一个）：词头、音标、词频星级、考试标签、来源标签；难词时顶部一块提示（忘了几次 + 三个动作）；熟练度阶梯（可直接修改）；词族；释义（英英可展开）；**遇到过的所有原句**（标明出处，可跳回原文），按"适合做复习卡的程度"排序——句子里其它词都认识（i+1，借鉴 Migaku）的那句标"复习卡用这句"，其余注明"还有 n 个生词"；"让 Tibi 找包含它的新文章"；复习指标（下次复习、当前记得率、复习次数与忘记次数）与最近复习结果；熟练度变化时间线。
- **右侧抽屉"✦ Tibi"**：近义词辨析、用所选词出题（不影响复习排期）、找出"遇见多但一直没进步"的词；难词多一问"为什么我老忘这个词"（分析忘记发生在哪种题型，建议换题型 / 对比卡）。
- 不借的：LingQ 的自动语法标签（对英语学习者价值低）、Lute 的词图片（成本高）、Relingo 的文件夹（与标签重复）。

**复习（FSRS）**（2026-10-30 参考开源项目词光 Word Atlas 改版，决策 G1–G8，调研见 [`research/05`](../research/05-word-atlas-review.md)）：
- 加入生词本（或熟练度设为见过 / 眼熟 / 认得 / 熟悉）即生成复习卡片；阅读时点开生词也会（R5，§3.2）。标为已知（97）不建卡。
- 每日：到期卡片 + 新卡片（每日新卡上限可设，默认 20）。**先到期、后新词**：注意力最好的时候先清到期的。
- **核心原则：用户只管答题，评分交给系统**（G1）。有标准答案的题（选义、填空）答完由系统按"对错 + 用时 + 是否用了提示 + 拼写距离"给出评分；只有"识别"题让用户自评。系统评分用一行小字显示，可以改。
- **计分复习只有三种题**（R6，2026-10-31 确认）：识别和语境回忆的难度相近，适合交给记忆算法排期；听写、拼写、造句难度差得多，混进同一张卡会让算法算出的"稳定度"失真，所以移到不计分的**练习**里（见下方"练习"）。**M1 只有选义、填空两种**：生词 / 见过出选义，眼熟及以上出填空。识别题在 M3 加入：

| 熟练度 | 题型 | 正面 | 作答 | 评分 | 训练目标 |
|---|---|---|---|---|---|
| 生词 / 见过 | ① 识别（M3） | 原文句子，目标词高亮 | 心里回答 → 显示答案（空格） | 自评四档 | 认识 |

- **系统评分规则**（G1，阈值按题型，正式版用个人中位用时校准；Core 的 `grade_answer` 负责）：答错或没作答 → 忘了；答对但慢（选义 > 9 秒、填空 > 15 秒）、用了提示、拼写只差一点 → 模糊；答对 → 记得；选义 3 秒内、填空 6 秒内又快又对 → 轻松。评分理由与下次间隔一起显示（"记得 · 答对，用时 4 秒 · 13 天后再见"）。
- **选义题的干扰项**（G2）：同词性、同难度、中文不重叠；优先取同一篇文章里的其他生词、易混词（affect / effect）、生词本里的词——干扰项本身也是一次复习。答错时在选错的那项旁注明它是谁的意思（"易混词 effect"）。
- **只有第一次作答算数**（G3）：每张卡在一轮里只有首次作答更新 FSRS、写 `review_logs`、计入正确率。答错的词在 3 张之后**换一种题型重练**（选义 ↔ 填空），最多两次，标"不计分"。
- **新词先初见**（G4）：没在文章里见过的新词（生词本"添加"、导入词表）5 个一组，先看"初见"卡（词头、音标、释义、词典例句与译文、发音，Enter "认识了"），再打乱顺序用选义回忆。读文章时标的词已经在语境里见过，直接进题。
- **提示由用户要**（G5）：填空默认只给中文提示；"提示一个字母"一次露一个，用了提示系统评分最高为"模糊"。

> 可交互原型：[`docs/prototypes/review.html`](../prototypes/review.html)（顶部"复习 / 练习"切换；网址加 `#practice` 直接进练习）。

**复习页交互**：
- **页面**：顶部分段进度条（每一步一段；首次作答按评分着色，初见为浅灰，重练步更窄、对绿错红）与"第 N / 共 M 步 · 还剩约 n 分钟"，右侧"稍后继续"；中间一张卡片只放题目与答案；**动作区固定在底部**（显示答案 / 检查 / 认识了 → 答完后是"评分行 + 继续"，自评题是四个评分按钮；键盘提示与"撤销上一张"也在这一行）；左栏列出今天的复习队列（圆点颜色 = 首次评分，新词标"新"）；顶栏右侧"复习 / 练习"分段切换。
- **卡片头**：题型、当前熟练度、上次复习距今多久（重练步显示"重练 · 不计分"，初见显示新词来源）、✦ 问 Tibi。
- **答案区**：词头、音标、发音、释义、原句及中文、易混提示（如 affect / effect）、出处与"回到原文"。输入题判定：正确 / 差一点（拼写相近）/ 不对，并在原句里标出正确答案；选义题正确项绿框、选错项红框。
- **评分行**（系统评分的题）：评分标签 + 理由 + 下次间隔 + "改评分"（展开四个按钮，按钮下有间隔；直接按 1–4 也能改）；"继续"按 Enter。改过的评分记为 `suggested_rating ≠ rating`，用于校准阈值。
- **评分后**：卡片右上角显示熟练度变化（如"眼熟 → 认得"），卡片滑走进入下一张。
- **撤销**：`Z` 或"撤销上一张"（连同插入的重练步一起撤销）。
- **稍后继续**（G6）：每答一题自动保存进度；离开后再进复习页先看到"上次复习到一半：还剩 n 张，约 x 分钟"（接着复习 / 从头开始）；首页"待复习"卡片变成"复习做到一半 · 接着复习"。
- **问 Tibi**：右侧抽屉按需打开；**未作答时 Tibi 只给提示、不直接说答案**；作答后可问"为什么是这个意思""再给两个例句""和 effect 有什么区别"。
- **完成页**（G7）：`celebrate-review` 插画、词数 / **首次就答对的比例** / 用时、首次评分分布条、每个词的熟练度变化与下次见面时间（忘了的词标红，并注明本轮补练了几次）；**"读一篇用到这些词的短文"**——Tibi 先在订阅来源里找同时用到这些词的文章，找不到就写一篇 ≤ 300 词、生词率 ≤ 5% 的短文（标为"Tibi 写的"，可放进书架开始读）；**"再练 n 个错词（不计分）"**；查看生词本；连续学习圆环补满。M1 没有"趁热读一篇"（依赖技能）。
- **练习**（G8，不计分，成绩单独记录在 `practice_logs`，M3 起；R6 后多了拼写和造句）：复习页顶栏切到"练习"——四种模式：**听写原句**（听你读过的句子写下整句，按词对齐标出漏写 / 写错）、**拼写**（中文释义 + 发音 + 字母数，拼出单词）、**易混词辨析**（在句子里二选一，选完给一句解释）、**造句**（给目标搭配，写句子，Tibi 批改）；句子来自最近复习 / 错词 / 难词 / 某篇文章；每轮 5 句，结束显示准确率、"再来一轮"。跟打练习已砍（2026-10-31）。
- **快捷键**：空格 显示答案、Enter 检查 / 认识了 / 继续、1–4 选择选项或评分 / 改评分、Z 撤销、L 问 Tibi、P 播放。

**评分与熟练度联动**（原型规则，正式版可调）：忘了 → 降一档；模糊 → 不变；记得 → 升一档；轻松 → 升一档（生词 / 见过 / 眼熟时升两档）。复习过一次后熟练度至少是"见过"（"生词"只表示还没在复习里见过它），所以一张生词卡无论评什么都会变成"见过"；稳定性超过约 60 天才可能升到"掌握"。

**排期**：FSRS（`ts-fsrs` 6.x，跟随它的默认 FSRS-7，2026-10-31 定；FSRS-7 多一个短期稳定度、按小数天计算，字段见 01 §4），默认参数，目标保持率 90%；原型内用简化实现展示间隔，正式版支持按个人复习记录优化参数。
- **语境轮换**：同一个词有多个语境时，每次复习换一句，避免"记住句子而不是词"。
- **阅读中再次遇见不改排期**（R7，2026-10-31 确认）：读到一个正在复习的词但没点开，不能说明记住了（可能只是跳过），所以只作弱信号——计入遇见次数，用于"遇见多但一直没进步"视图和挑复习语境，不更新 FSRS。
- **"掌握"的标准**保持稳定性约 60 天（词光用 21 天）：Tibi 的熟练度同时用于阅读着色，标准更严。

> ✅ **D3（已确认）**：一词一卡，题型随熟练度递进。R6（2026-10-31）后计分复习只有识别 / 选义 → 填空三种，听写、拼写、造句移到练习。M1 只有选义、填空。

### 3.4 音频（Audio）

### 3.5 首页与书架（Home & Library）

> 可交互原型：[`docs/prototypes/home.html`](../prototypes/home.html)。

**设计方向 v2（安静的 AI 工作台）**：首页的主角是一个大输入框，AI 面板只在执行任务或对话时出现。

**左栏**（与底色同色，可折叠为图标栏 `⌘\`）：Logo、搜索（`⌘K`，搜文章、单词与设置）、导航（首页 / 书架 / 生词本 / 复习〔待复习数徽标〕/ 统计 / 任务〔运行中 + 待确认数徽标〕）、**最近**（最近 3 次对话 + 读到一半的文章，对话带气泡图标、文章带文档图标；点对话回到那次对话页，当前对话高亮）、底部连续学习圆环（今日分钟数进度）与用户（估算词汇量、设置）。

**顶栏**：只有面包屑和深浅色切换。首页不放 Tibi 入口和搜索——中间的大输入框本身就是对话和导入入口，搜索在左栏。

**导入入口只有一个**：首页的大输入框。左栏不再放"导入文章"按钮（它和"首页"导航、输入框的"导入"模式重复）；任何页面按 `⌘N` 回到首页并切到导入模式，拖文件进窗口也直接导入。

**主区**（白色圆角面板，自上而下）：
1. **大输入框**："下午好，今天想读点什么？"，一个输入框承担三种模式（分段切换）：**导入**（粘贴网址 / 文字，或拖入 PDF、EPUB、DOCX、图片）、**问 Tibi**、**找文章**（按水平和兴趣推荐）；右侧"快速 / 深入"档位（只对这一次生效，覆盖该技能的默认模型档）与发送按钮。粘贴网址时自动切到导入模式。
2. **建议任务**（输入框下方的胶囊）：继续阅读某篇、复习到期的词、推荐一篇 10 分钟的新闻、用本周生词写小故事。
3. **今天**：三块浅灰底卡片——待复习（张数、预计时长、开始）、今日阅读（分钟 / 目标、进度条）、已知词（词汇量、本周增长、连续天数七段条）。
4. **继续阅读**：两张横向卡片，显示类型、标题、开头一句、进度与剩余时间。
5. **书架**（首页上只是最近的一截，右侧"全部书架 →"）：形态分段控件（全部 / 文章 / 书）；卡片默认**不显示封面**（`cover_path` 字段保留，设置里开启后有封面的文章才显示）：类型与进度、标题（Charter）、开头一句、难度与生词率、最多两个标签；书的卡片多"第 n / N 章"和"本章 + 全书"两段进度条。

**书架页**（左栏"书架"，可交互原型：[`docs/prototypes/library.html`](../prototypes/library.html)）：顶部一行工具：页内筛选框、**形态分段控件**（全部 / 文章 n / 书 n）、排序（**最适合我** / 最近打开 / 最近导入 / 按进度 / 按时长）、网格 / 列表切换，右侧提示"封面已关闭 · 在设置里开启"；标题旁一句概览（n 篇文章 · n 本书 · 读到一半 · 读完）。下面一行是**标签筛选**：系统类型（技术 / 新闻 / 文学 / 学术，灰底、不可删）在前，用户标签（带计数、按使用次数排）在后，用细线隔开，可多选（同时满足），右侧"清除"。"最适合我"按生词率接近学习区（约 4%）排序，读到一半的靠前、读完的另成一组"读完了"。一本书只占一张卡（作者、第 n / N 章、两段进度），点开进阅读器后左栏展开目录。列表视图是一张表：标题（含来源 / 章节）、类型 · 标签、时长、难度与生词率、进度、最近打开。每张卡片悬停出现"…"菜单：继续阅读（书为"继续读第 n 章"）/ **标签**（一排已有标签点选，"＋ 新标签"）/ **类型**（改后着色与总结策略按新类型重新生成）/ 重新分析（用当前词库）/ 导出 Markdown / 删除（可撤销）。空状态与首页一致。

**吉祥物**：标题上方是藏狐（SVG 动画）：平时待机；输入框获得焦点时倾听；导入时捧书阅读，找文章、问 Tibi 时思考；完成时开心；深夜打开时在睡觉；Tibi 要你确认时惊讶一下；点它会开心。

**`/` 选择要做的事**：输入 `/` 弹出动作列表（导入文章、找文章、讲解、出题与批改、学习洞察、整理记忆），选中后输入框上方显示动作标签；直接打字也行，Tibi 自己判断该用哪项技能（例如"这句为什么用 had been"→ 讲解、"出 10 道题"→ 出题）。

**第一次使用**：不再单独放介绍卡片（2026-10-31 删除，与输入框、建议胶囊和 `/` 菜单重复）；空书架时首页给三篇示例。

**发送后进入对话页（D9，借鉴 ChatGPT / Claude 的"首页只是入口"）**：首页本身没有右侧抽屉。按下发送后，主区整体切换成一个独立的对话页：顶栏面包屑变为"首页 / 导入文章"（或 找文章 / 对话），内容居中、最宽 760px，底部是"继续问 Tibi…"输入框；点面包屑"首页"或按 `Esc` 回到首页，对话会出现在左栏"最近"里（标题取第一句输入或文章名；手机上的"今天"对话同步过来后显示为"10 月 31 日 · 手机"），点一下就能回来继续；正在跑的任务在任务中心继续，结果写回它自己的那次对话。
- **导入**：步骤清单（获取内容 → 提取正文与结构 → 分句、词形还原 → 对照你的词库标注 → AI 总结、短语与难点）逐项打勾并显示耗时，下方实时日志（抓到多少词、类型判断、生词率…）；完成后给出结果卡片（形态 · 类型、时长、难度、**Tibi 建议的标签**〔默认采纳，点一下取消，"＋ 自己加"〕、总结）与"开始阅读 / 在书架中查看"，书架最前面同时出现这篇。
- **找文章**：同样展示检索步骤，最后给出带推荐理由的文章卡片。
- **问 Tibi**：对话；可直接把网址发给 Tibi 导入。用到某项技能时显示一张收起的过程卡（"Tibi 正在讲解…"，点开看步骤）；Tibi 要写入记忆等数据时出现审批卡。
- 对话页顶部写"Tibi 正在导入这篇文章 · 离开页面也会继续"，链接到任务中心；结果下方是"Tibi · 技能名 · 查看过程"，模型、用时、花费放在查看过程里。

右侧抽屉只保留给阅读器（总结 / 生词 / Tibi）、生词本（详情）和任务中心（任务详情）这些"主区内容还要看着"的场景；首页发送指令后主区内容不再需要，所以不用抽屉。

### 3.6 学习统计（Stats）

> 可交互原型：[`docs/prototypes/stats.html`](../prototypes/stats.html)。统计面板排在 M3；M1 只有本地统计与导出（[§6](#m1-成功标准)）。

顶部右侧切换统计范围（30 天 / 90 天 / 半年），整页随之变化。自上而下：

1. **四项指标**（浅灰卡片，右上角各有一条 12 周走势小线；点卡片滚到对应图表）：已知词数（即词汇量；本期增长、与上一周期对比）、阅读时长（总词数、每周词数）、学习天数（连续天数、最长连续）、复习次数（"记得 / 轻松"占比）。
2. **Tibi 的洞察**（浅蓝卡片）：一段话总结本期变化（例如"技术文档生词率从 9% 降到 7%，新闻读得少"），并附可直接执行的建议按钮（复习到期的词、找一篇学习区的新闻）。只在打开统计页时生成，不主动推送。卡片底部注明"Tibi · 学习洞察"，可查看过程、重新生成。
3. **已知词数曲线**（词汇量，最核心的成就指标；"已知" = 熟练度为熟悉 / 掌握的词 + 标为已知（97）的词 + 词汇量测试与预标注推断为已知的词，和熟练度里的"掌握"不是一回事）：面积折线图，悬停显示十字线与当日数值；可切换为表格查看。
4. **每日阅读**（最近 30 天柱状图）：达成每日目标的天为强调色，未达成为浅灰，虚线标出目标分钟数。
5. **接下来要复习**：未来 14 天每天到期的卡片数，今天为强调色；下方注明目标记得率与实际记得率。
6. **复习表现**（借鉴 Anki 的 True Retention）：最近 12 周每周四档评分的堆叠柱 + 记得率折线（目标 90% 参考）；右侧三个数：12 周记得率、忘了的次数、难词数（链接到生词本"难词"视图）。
7. **学习日历**：最近 26 周热力图，按每天学习分钟数分五档（强调色由浅到深），悬停显示当天分钟数与阅读词数。
8. **生词本熟练度**：六档分布条与数量，标题旁链接到生词本。
9. **按类型阅读量**：技术 / 新闻 / 文学的阅读词数横条，以及各类型的平均生词率。

图表配色：只用强调色与灰色，不引入新颜色；熟练度分布沿用荧光笔标注色。深浅色切换、窗口尺寸变化时重绘。

**空状态**：还没有学习数据时整页换成吉祥物 + "还没有可以统计的东西" + 去首页读一篇 / 看看示例数据（原型 `#empty`）。洞察卡的动作与数据挂钩：复习到期的词、找学习区的新闻、看看难词。

### 3.7 设置（Settings）

> 可交互原型：[`docs/prototypes/settings.html`](../prototypes/settings.html)。

单页长列表 + 左侧分组导航（顶部一个**页内搜索框**，按 `/` 聚焦：按设置项过滤、命中文字高亮、每组显示命中数，找不到时提示用 ⌘K；滚动时高亮当前分组）。每组标题右侧有"恢复默认"。修改即时生效并自动保存，顶栏右侧提示"已保存"，没有"保存"按钮。分组：

- **通用**：外观（跟随系统 / 浅色 / 深色）、书架显示封面（默认关）、界面语言、英语水平与目标（"校准词汇量"打开 `onboarding.html#step=2`，测完回到设置）、常读材料类型（多选，影响推荐）。
- **阅读**：正文字体（Charter / Source Serif / Geist）、字号、标注强度（全部 / 仅生词 / 纯净阅读）、默认显示译文、默认显示行间释义、释义语言（中文 / 英英 / 都显示，对应 D5）、读完后剩余生词是否标为已知（询问 / 自动 / 从不）。
- **学习与复习**：每日阅读目标、每日新词上限、目标记得率（80–97%，旁边实时显示对应的每日复习量）、是否出识别题（M3 起；关掉后由选义代替）、按个人复习记录优化排期参数（记录不足 400 条时提示）。
- **模型**：
  - 服务商列表：DeepSeek（文本，默认）、视觉模型（可选，不配置时用本地 Tesseract）、图像模型（可选，用于生成封面）、添加任意 OpenAI 兼容服务商。每项可展开编辑 Base URL、API Key、模型，并"测试连接"（逐行显示连接、模型可用性、结构化输出测试）。API Key 存系统钥匙串，不写数据库。
  - 两档模型：快速（默认 deepseek-v4-flash）、深入（默认 deepseek-v4-pro），每项技能用其中一档。模型名是配置项，不写死。
  - 只用 API Key，不做账号登录（2026-10-31：ChatGPT 条款未核实，先不做；Claude 订阅登录被 Anthropic 条款禁止，见 05 §10）。Anthropic API Key 照常可用。v1 不接入本地 ACP 工具。
- **Tibi**（2026-10-30 从"模型与 Tibi"拆出：模型是"用什么"，这一组是"它怎么对待你"）：
  - 权限模式（对应 A3）：每次都问 / 标词自动、其余询问（默认）/ 全部自动。
  - Tibi 怎么称呼你、对话语言（A7 调整：Tibi 自己的名字固定——它就是吉祥物）。
  - 允许其他 AI 工具通过 MCP 使用 Tibi（对应 A6，默认关闭），开启后显示可复制的接入配置；默认只开读能力白名单，写能力逐项开启，开启后同样按权限先问，记录在任务中心。
- **Tibi 的技能**：每项技能一行（动词命名：导入文章、找文章、讲解、出题与批改、学习洞察、整理记忆；模型档、本月花费），展开后可改模型档、附加指令、写入权限，查看用到的能力与最近记录，恢复默认；每月预算、单个任务上限。技能只能配置，不能新建或安装。
- **语音**：朗读引擎（系统语音 / Kokoro 本地模型，需下载约 86 MB，显示下载进度 / 云端语音）、音色（美音、英音各两种，点击试听）、默认语速。
- **记忆**：列出 Tibi 记住的内容（身份、兴趣、观察、指令、日志），注明来源与日期；可逐条编辑、删除（可撤销）；暂停写入新记忆；清空全部（需再点一次确认）。生词与复习记录不在这里，它们直接来自学习数据。
- **数据**：数据库位置（可在 Finder 中显示、迁移）、自动备份（每天一次，保留 7 份）与恢复、导出生词本（CSV / Anki）、**导出学习汇总**（脱敏，只有计数，[§6](#m1-成功标准)）、从其他工具导入已知词、词典版本、清理语音缓存。
- **关于**：版本、MIT 协议、检查更新、致谢的开源项目。
- 危险操作放在"数据"组最底部："重置 Tibi"（先自动备份，再清空全部数据并回到首次使用引导），需点两次确认。

### 3.8 全局搜索（⌘K）

> 原型：所有页面左栏顶部的"搜索"，或按 `⌘K`（共享脚本 [`v2-search.js`](../prototypes/v2-search.js)）。

居中浮层，一个输入框搜所有东西，找不到就直接问 Tibi：

- **范围**：全部 / 文章 / 单词 / 设置 / 操作，点击或 `Tab` 切换。
- **空输入时**：最近搜索（可清除）、继续阅读的文章、快捷操作（导入文章、开始复习、切换深浅色）；切到"单词"显示最近加入的词，切到"设置"列出设置分组。
- **结果**：
  - **文章**：匹配标题，也匹配正文句子（显示命中片段与所在文章）。
  - **单词与短语**：匹配英文或中文释义，显示熟练度标签和一句原句；打开后跳到生词本并选中这个词。
  - **设置**：匹配设置项名称和关键词（如输入"深色""api key""fsrs"），打开后滚动到该项并闪一下浅蓝底。
  - **跳转与操作**：页面（首页、书架、生词本、复习、统计、设置）和动作（导入文章、开始复习、切换深浅色）。
  - 分组顺序按匹配程度：输入单词时单词组在前，输入页面名时操作在前；匹配处用浅蓝荧光笔标出。
  - 最后一行永远是"问 Tibi：'…'"（`⌘↵` 直接发送）：首页切到对话页，阅读器发到 Tibi 面板（附带当前文章上下文）。
- **键盘**：`↑↓` 选择、`↵` 打开、`Esc` 先清空再关闭；关闭后焦点回到原处。
- **正式版**：文章正文搜索用 SQLite FTS5；单词同时查 ECDICT，未加入生词本的词可直接查词卡、加入生词本。

### 3.9 首次启动引导（Onboarding）

> R3（2026-10-31 确认）。可交互原型：[`docs/prototypes/onboarding.html`](../prototypes/onboarding.html)。网址编号沿用原型：`#step=2` 校准词汇量、`#step=3` 连接模型，都不在主流程里，按需单独进入，完成后回到来处。

没有侧栏，一张居中的卡片：左边是 Tibi（藏狐，SVG 小狐狸）、它说的一句话和两步进度，右边是当前这一步；底部"上一步 / 跳过 / 继续"。

**引导只有两步**：

1. **先认识一下**（可跳过）：Tibi 怎么称呼你、学英语是为了（工作阅读、读原版书、雅思 / 托福、考研 / CET、兴趣）、自评水平（入门 / 中级 / 中高级 / 高级，对应 A2–C1）、**常读材料类型**（多选）。写入 `user_profile` 与 Tibi 的用户画像记忆；Tibi 说话的语言留在设置里，默认中文夹英文。自评水平给出初始词汇量估算（`vocab_source = self`）：入门约 2000、中级约 3500、中高级约 6000、高级约 9000，跳过时按中高级。
2. **读第一篇**：技术向内置示例默认选中，另有小说、新闻各一篇；也可以粘贴网址或一段英文。导入过程显示进度，完成后"开始阅读"直接进阅读器，或"先不读，进入 Tibi"回首页。

**内置示例**随应用打包预生成的 AI 结果（总结、语境释义），不用配 Key 就能体验；示例里没覆盖到的词只显示词典释义，不要求连模型。

**不在引导里的两件事**：

- **校准词汇量**（`onboarding.html#step=2`，3–4 分钟，可跳过）：读完第一篇时用建议卡提议，设置里也能进。按词频分 7 组（前 1k / 1–2k / 2–4k / 4–6k / 6–8k / 8–10k / 10k+），4k 以下每组 8 个词，4k–10k 每组 10 个，**点亮确定认识的**；每组混 2 个伪词（如 *flandish*）防乱点，点中伪词按比例下调估算。**R8（2026-10-31 确认）**：4k–10k 是大多数目标用户所在的区间，原来只有一组，现在拆成三组加密；伪词从每组 0–1 个提高到 2 个；读完第一篇后用实际标注修正一次估算。统计页的已知词曲线拆成**实测**（用户亲手标过、测试点亮、复习答对的词，实线）和**估算**（按规则推断的词，虚线）两条。结果页：估算词汇量（取整到百）、对应 CEFR（与自评不一致时以测出来的为准）、各组认识比例的小柱图、以及 Tibi 会怎么用它（按 [§3.1 的中间带规则](#31-文章导入import)）；数不对可以手填。完成后按新估算重新标注（不重新调用 AI）。
- **连接模型**（`onboarding.html#step=3`）：第一次对用户自己的文章用 AI 时才要求，在此之前首页显示未连模型状态，不打断阅读；词卡先显示词典释义。三种方式：填 API Key（DeepSeek 推荐 / OpenAI / Anthropic / 其他兼容 OpenAI 的服务，Key 只存本机；"测试连接"成功后显示两档模型默认选谁），或本地模型（检测 Ollama）。不提供账号登录（见 B6）。不连模型时查词、标注、复习照常。

**跳过测试时**，预标注按自评估算，准确性较低；界面在标注说明里写明"按你的自评估算"，用户可随时校准。

### 3.10 Tibi 与技能

> 内部架构（多智能体、能力层、运行时）见 [`05-agent-architecture.md`](./05-agent-architecture.md) §3–§8；用户可见层的规则见 §13（2026-10-29 确认）。上下文、记忆、工具、权限见 [`02-ai-assistant.md`](./02-ai-assistant.md)。

- **用户只面对一个角色：Tibi**。它是吉祥物藏狐，也是 AI 助手；常驻、懂上下文（正在读的文章、选中的句子、当前卡片），有用户身份、能力认知、学习记忆。
- **界面上叫"Tibi 能做的事"，用动词命名**（R14，2026-10-31 确认）：导入文章、找文章、讲解、出题与批改、学习洞察、整理记忆。"技能"是内部的词，界面上只在"查看过程"和设置 → 高级里出现；FSRS、ECDICT、能力名这类实现词不出现在界面上。其中**导入文章是固定流水线**（R10：步骤由代码固定执行，模型只做总结等生成步骤，离线也能完成本地部分，用户自己触发不再审批）；其余 5 项是技能，每项内部是一份 `SKILL.md`（指令 + 能用的能力 + 模型档），随应用分发，用户不能新建或安装；运行时每项技能是一个独立的子对话（内部实现上就是一个专职 agent），但界面上不出现"智能体 / 子智能体 / 委派"这些词。
- **怎么用**：
  - 就地按钮：词卡"更多解释"、选中句子"问 Tibi"、复习页"为什么"、统计页的洞察——不用知道是哪项技能；
  - 首页输入框不分模式（R13）：粘贴网址或拖入文件就导入，其余内容是问 Tibi，Tibi 自己判断要做哪件事；
  - 输入 `/` 选择要做的事；⌘K 搜索的最后一行"问 Tibi"；
  - 外部 AI 工具（Codex、Claude Code 等）通过 MCP 调用 Tibi 的能力。

  所有技能都由用户触发，没有定时运行：找文章、整理记忆只在手动选择时跑。
- **过程可见，但默认收起**：处理时显示"Tibi 正在…"，步骤点开才看；产出下方是"Tibi · 技能名 · 查看过程"；模型、用时、花费、工具调用只在"查看过程"和任务中心里出现。
- **权限**：Tibi 写入数据时按权限模式先问你（审批卡"Tibi 想…"，可"以后这类都自动允许"），所有写操作可撤销；只用 Tibi 自己的能力，不执行任意代码。
- **可配置**：设置 → Tibi 的技能（默认不用管）：模型档、附加指令、写入权限；每月预算与单个任务上限。
- **模型来源**：默认 DeepSeek API Key，也可填 OpenAI、Anthropic 或其他兼容服务的 Key；不做账号登录（ChatGPT 条款未核实，Claude 订阅登录被条款禁止）。v1 不做 ACP 客户端。

### 3.11 任务中心（Tasks）

> 可交互原型：[`docs/prototypes/tasks.html`](../prototypes/tasks.html)。本节是完整版，排在 M5；此前进度显示在发起处（导入卡、对话页），审批卡出现在对话里。

左栏"任务"（徽标 = 运行中 + 等你确认）。自上而下：四项概览（运行中、本周完成、本月花费 / 预算、花得最多的技能）→ **等你确认**（允许 / 拒绝 / 修改后允许 / 以后这类自动允许；含外部 AI 工具经 MCP 发来的请求）→ **运行中**（当前步骤、技能、用时、花费，可暂停、取消）→ **最近**（完成 / 失败 / 已取消，失败的从断点重试）。点任务在右侧抽屉看详情：状态、触发方式、模型、用量、嵌套步骤树、过程（消息与工具调用），可"在对话中继续"、复制诊断信息（不含 API Key 和正文）。

**复审（2026-10-30，参照 agent 界面的通行做法）**：
- 审批卡在正文下方多一行"将执行 `工具名` · 影响（写入 1 条记忆 / 新增 3 篇到书架）· 可撤销"，让"允许"是看清楚之后的决定，而不是习惯性点掉。
- 运行中的行显示"第 n / N 步 · 还剩约 x 秒"而不只是当前步骤名；任务做完后弹一条带动作的通知（"导入完成 · 开始阅读"），后台工作要主动告知完成。
- 历史按"今天 / 昨天 / 更早"分组。
- 键盘：`J` / `K` 在确认项与任务间移动，`Enter` 开详情，`A` / `R` 允许或拒绝当前确认项，`Esc` 关闭。
- 原型里运行中的导入任务会每隔几秒前进一步，演示进度、详情里的步骤树与完成通知。

### 3.12 空状态

> 原型：首页 / 书架 / 复习 / 任务 / 统计页左下角的"原型演示"开关，或网址加 `#empty`。生词本没有这个开关。

第一次打开、还没有数据时，每个页面都用同一种空状态：吉祥物（对应状态）+ 一句话标题 + 一句说明 + 最多三个动作。首页（书架为空 + 三篇内置示例，点一下就导入）、书架（去首页导入 / 让 Tibi 找几篇）、复习（没有到期卡片：去读一篇 / 提前复习）、任务中心（Tibi 还没做过事）、统计（§3.6）。生词本：当前视图或筛选没有结果时，列表位置显示 `empty-words` 插画和一句话；还没有对话和文章时，左栏"最近"显示"还没有对话和文章"。

### 3.13 手机端（D8）

> 原型：[`docs/prototypes/mobile.html`](../prototypes/mobile.html)（独立的壳，不与桌面页共用布局）。2026-10-31 按 iOS 产品调研改版（J1–J10），调研见 [`research/06`](../research/06-ios-apps.md)。

桌面端最小窗口 960px、不做手机适配；手机端是独立的壳，范围以**读 + 复习 + 问 Tibi** 为主，加上轻量导入（Safari 分享、粘贴网址，J3）；设置、任务管理、统计详情留在桌面端，手机端只看进度与确认。**手机可以单独用**（2026-10-31 确认）：手机里跑同一个 Tibi Core（R11 写成不依赖 Node 的 TS 包，放进应用自己的 JS 运行时），有自己的 `app.db` 和 API Key（存 iOS 钥匙串），导入、问 Tibi、复习都在手机上完成，电脑不开机也不影响；两端的数据靠同步合并（同步通道待定，排在 M7）。

- **标签栏**（J1、J9）：最左边是一个圆形的狐狸按钮，就是"今天"，选中时外观不变（右边胶囊里没有选中项即表示在"今天"）；右边是悬浮胶囊"书架 / 复习 / 我"，当前项浅蓝底，复习项带待复习数。已在"今天"时再点狐狸，直接把光标放进输入框。阅读器从卡片进入、全屏，不占标签。Tibi 的入口：首页（对话就在首页）、阅读器工具栏、词卡。
- **今天**（J2、J9）：没有顶栏和问候；最上面一行今天的进度（小圆环 + "今日 12 / 20 分钟 · 连续 9 天"），下面直接是一张"继续读"大卡（标题、进度、剩余分钟、继续）；一张复习卡（张数、预计时间、开始；做到一半时改为"接着复习"）；两条建议（已知词数挪到"我"）。输入条常驻在标签栏上方（粘贴网址即导入，其他内容即问 Tibi，右侧系统粘贴按钮）。发出去之后，对话接在卡片下面，导入结果也作为一条回复出现（带"去书架"）；当天的对话留在首页，第二天换新的一页，以前的在"我 › 对话记录"。数据上一天就是一次对话（`conversations.kind = day`）；同步到电脑后出现在左栏"最近"，显示为"10 月 31 日 · 手机"，点开可以接着聊。电脑上发起的对话同步到手机后也在"对话记录"里。两端各自保持自己的习惯（电脑一次一页，手机一天一页），数据模型是同一个。阅读器、词卡、复习完成页里问 Tibi 仍用底部面板，因为问题跟着当前文章或单词。
- **书架**：大标题，形态分段（全部 / 文章 / 书）、标签横向滚动、列表（标题、类型、章节或时长、生词率、进度）。右上角"+"打开导入面板（J3）：粘贴网址或文字、从"文件"选、拍书页，下面一行"在 Safari 里点分享，选 Tibi"。
- **从 Safari 分享**（J3）：分享扩展只显示网址和标题，"导入"或"稍后读"；进书架前不抓取正文，与桌面剪藏插件（R4）同一条深链。
- **阅读器**（J4）：全屏，向下滚动收起顶栏和底部工具栏，向上滚动或轻点正文空白处再出现；顶栏是返回、标题、标注说明；工具栏是译文、释义、朗读、外观、Tibi。文末是"读完了"卡片：把剩下的生词标为已知（带撤销）、出 3 道理解题、下一篇。不做"翻页即标已知"。
- **词卡**（J5）：底部面板，默认半屏，上拉全屏。点开生词即进"见过"并建卡（R5），显示"已加入复习 · 其实认识"；下面是 AI 语境释义、词典释义、六档熟练度、忽略和问 Tibi；全屏时多出遇到过的句子和复习数据。
- **复习**（J6）：与桌面端 G1–G8 一致（系统评分、选义、重练、初见、首次作答算数）。题目在上半屏，选项、评分行、"继续"和自评按钮都在下半屏；左上角关闭等于"稍后继续"；不做滑动评分（AnkiMobile 用户反映滑动识别不稳）；答对轻震一下，答错震两下。复习标签的入口页显示今天的张数，下面是两种不计分的练习。
- **我**：右上角深浅色与设置；连续天数圆环（下面一行今日分钟与已知词数）、本周阅读、生词本、对话记录、Tibi 记忆、任务（等你确认的数量）、每日提醒、同步、小组件与分享（演示）。
- **小组件**（J7）：主屏小号（狐狸 + 待复习数 + 连续天数）、中号（继续读的文章与进度 + 复习数）；锁屏圆环（今日分钟）与一行文字（复习数 · 连续天数）。狐狸只有平静和开心两种状态，不用惊慌的表情制造愧疚感；不用实时活动。
- **提醒**（J8）：每天一条，时间可选（关闭 / 早上 / 中午 / 晚上），内容是当天待复习数。
- **字体**：系统字体（SF Pro + 苹方），与桌面端一致；正文仍是 Charter。
- **外观**（J10）：照 iOS 原生应用做：系统分组背景色、无描边白卡片、胶囊按钮、圆形玻璃导航按钮、选中时换实心图标、设置式彩色图标列表；不用投影和背景渐变。规格见 03 手机壳。

与桌面端同步方案待定（局域网 / iCloud 文件夹 / 自建），排在 M7；手机端 Core 怎么跑见 R11。

## 4. 系统架构

架构图与说明见 [`05-agent-architecture.md` §3](./05-agent-architecture.md#3-进程架构)（2026-10-29 确认，替代原"界面直连数据库 + 自写 agent 循环"的方案）。

**设计原则**：
1. **本地优先**：无网络、无 API Key 时，导入（文本/网页/PDF/本地 OCR）、阅读、着色、词典、复习、系统 TTS 全部可用；Tibi 的技能是增强层，离线时跳过并标出"可稍后补做"。
2. **确定性的用代码，判断和生成交给技能**：分词、词形、查词、FSRS、统计是能力；总结、讲解、推荐、出题、批改、洞察、整理记忆是技能（由模型完成）。
3. **能力即工具**：界面、技能、外部 AI 工具（经 MCP）调用的是同一套能力。
4. **过程可见、可控**：技能的每一步写入存储后才显示，可在任务中心查看、暂停、取消、重试；写入数据按权限先问、可撤销；花费按技能统计并受预算约束。
5. **AI 结果全部缓存**：同一内容不重复调用，切换模型后可手动重新生成。
6. **业务逻辑在 TypeScript**：降低开源贡献门槛；Rust 只做壳。

## 5. 数据库

初版表结构草案见 [`01-database.md`](./01-database.md)。核心实体：

- **documents / sections / sentences**：文档（文章或整本书）→ 章节 → 句子（阅读、语境、朗读的基本单位）
- **terms**：用户的词条（单词或短语，含学习状态）——**已知词库**
- **term_forms / term_status_log**：词族里出现过的词形、熟练度变化时间线
- **term_contexts**：词条的语境（文章原句、词典例句或手动添加）
- **cards / review_logs / review_sessions**：FSRS 复习卡片、复习记录（只记首次作答）与进行中的复习会话
- **practice_logs**：练习成绩（不影响排期）
- **ai_results**：AI 分析结果缓存
- **providers / settings / user_profile**：配置
- **skills / thread_links / skill_audit**：技能配置、对话线程与文章的绑定、写操作审计
- **conversations / messages / jobs / job_steps / usage_records**：对话、消息、任务与步骤检查点、用量（R9 后自建，不再用 pi-durable）
- **memories / learning_events**：助手记忆与学习事件日志

## 6. 版本规划（建议）

R1、R2（2026-10-31 产品负责人确认）。

### M1 成功标准

**验证方式**：本地统计 + 5–10 人访谈。数据只在本机；用户在设置 → 数据里一键导出脱敏汇总（`stats.export_summary`，只有计数，不含词和正文），看过内容后自己发给作者。**不做上报。**

通过线（2026-10-31 定，起始值，无外部基准，样本小时只作信号）：

| # | 假设 | 指标 | 通过线 |
|---|---|---|---|
| **H1** | 预标注准 | 用户读完第一篇前改动的预标注词占预标注词总数 | ≤ 15% |
| **H2** | 持续导入 | 首次使用后 7 天内自己导入至少 1 篇（不含示例）的人数比例 | ≥ 40% |
| **H3** | 回来复习 | 第一次产生复习卡后的次日完成至少一次复习的人数比例 | ≥ 30% |

口径与数据来源见 [01 §6](01-database.md#m1-成功标准的数据来源)。

### 里程碑

| 阶段 | 目标 | 范围 |
|---|---|---|
| **M0 技术验证 + 骨架** | 能跑起来 | 先按 05 §11 做一到两周技术验证（Tibi Core + `pi-agent-core` + 自建对话 / 任务表与领域表共库、中途杀进程能续跑、DeepSeek 工具调用、导入做成可续跑任务、审批挂起、三平台打包、Core 不依赖 Node 专有 API 以便手机复用）；再搭 Tauri + React + shadcn 脚手架、Tibi Core sidecar、SQLite + 迁移、ECDICT 入库、设计系统 |
