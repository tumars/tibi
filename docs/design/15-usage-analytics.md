# 可选使用统计

2026-11-18。根据用户授权接入 Mixpanel 官方浏览器 SDK 2.86.0，复用项目 4084746（US），`product=tibi`，`site=app`，区分 web、desktop、mobile。SDK 从应用包加载，不依赖外部脚本。

默认关闭，桌面“设置 → 数据”和移动“我”提供同一开关；选择仅存在当前设备的浏览器存储，不进入学习同步或备份。仅主动开启后初始化 SDK，记录启动、成功且非重复导入、查词成功和提交复习答案成功。只允许平台、版本、语言、环境、随机标识、事件时间等协议和公共属性通过发送白名单。

不采集文章、文件、路径、来源 URL、词句、答案、对话、模型 Key、同步信息。关闭自动采集、来源及营销自动采集、IP 地理解析和会话回放。尊重 DNT/GPC；随机标识属于持续标识符，不宣称完全匿名。关闭开关会清除 SDK 本机标识与待发队列，其他标签页同步撤回。离线重试使用 SDK 持久队列，不自建上报后端。已发送数据不会自动删除，可联系作者协助处理。

生产事件 `environment=production`，开发默认不发送；显式验收参数 `analytics-test=1` 发送的开发构建事件标记为 development。Tauri CSP 仅补充 US 采集域名 `https://api-js.mixpanel.com`，不放宽其他来源。官网流量和应用内使用分开统计，不承诺跨设备、跨官网安装去重。

隐私政策、README 和使用指南同步改为上述边界。实施与验证状态见 ferecord 仓库 `docs/analytics-design.md`；本次发布 Web 版，没有发布新原生客户端或自动开启任何用户的统计。Web 工作流固定 `EDGEONE_PAGES_API_REGION=china`，使用已有腾讯云 Makers 项目，避免将中国站 Token 发往国际站接口。
