# 本机分发管理台

2026-11-17：为 Tibi 提供可自行运行的网页服务，管理独立 COS 桶、版本发行和应用内公告。启动命令 `pnpm admin`，默认地址 `http://127.0.0.1:4311`。使用 Node.js 24 与现有 AWS CLI，不增加云服务器、数据库或新的构建流程。

## 页面与操作

- **概览**：显示分发连接、线上版本、已发布公告、本机草稿及最近任务。
- **文件存储**：按目录浏览、分页，查看大小和修改时间，打开或复制公开链接；普通文件上传至 `uploads/`，允许删除该目录的文件。`latest.json`、`notice.json`、`latest/`、版本目录只可查看，分别通过专门发布流程修改。
- **版本发布**：选择本机发行目录，检查清单、文件、SHA-256 与更新包 Ed25519 签名；预览平台、安装包和文件大小后确认发布。只发布高于线上版本且 COS 尚不存在的新版本。正式安装包仍须先完成 Apple 签名、公证或对应平台的发行验收。管理台挑选发行文件，排除日志、私钥与目录，将经检查的产物复制到临时目录再次校验后复用现有发布工具。最后切换更新清单。
- **公告推送**：用表单编辑中文、英文、按钮、目标平台、旧版本范围与截止日期；可预览、保存本机草稿、载入线上内容、确认发布。与客户端共用公告格式校验，发布使用保存后的快照。本机草稿保存到仓库 `notice.json`，发布记录与快照保存在被忽略的 `.tibi/admin/`。移除公告后重新发布即可停止后续展示。

公告沿用客户端定时拉取，不是操作系统即时推送：桌面遵循自动检查开关，每天检查；移动端每天检查。一般公告同一 ID 只展示一次，低版本提醒每天一次，更新后不再出现。编辑已推送公告时如需再次提醒，使用新的 ID。页面明确展示这一规则，不承诺即时送达或阅读人数。

## 服务边界

只监听 `127.0.0.1`；校验 Host、Origin 和管理请求头，不开放跨域访问。凭据只在服务端读取本项目 `.env.cos`，不会返回浏览器。静态服务仅提供管理台自身文件，不开放任意本机文件访问。上传采用流式落盘，大文件不整体加载进内存；COS 操作和发布异步执行，单次只运行一个写任务，页面显示任务日志、成功或失败，重启后未完成任务标记为中断。

专用 CAM 策略在现有 Tibi 对象读写、分片上传权限上增加 Tibi 桶文件列表读取；仅为 `uploads/*` 增加删除权限，不修改画海授权。管理台同时在服务端拒绝通过普通文件接口改写发行文件和公告。

本次开发和验收可以读线上真实状态、使用 `uploads/` 测试文件验证上传与删除；不发布新客户端版本，不向用户推送测试公告。验证状态随实现更新到 `docs/dev/tencent-distribution.md`。
