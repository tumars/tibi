# Mac App Store 分发

2026-11-06 17:19（Asia/Singapore）：**0.1.0 (2) 已成功提交 App Review**，审核通过后自动发布，当前尚未上架。首包的 ITMS-91109（描述文件下载隔离属性）已修复，构建 2 在 Apple 后台处理成功。原有 DMG 分发继续保留。

## 构建边界

- 官网版使用默认 Cargo feature `direct-distribution`，保留私有窗口 API 和自更新器。
- 商店版使用 `--no-default-features --features app-store`，覆盖 `tauri.appstore.conf.json`。两种 feature 不可同时开启。
- 商店版窗口不透明，不调用 vibrancy；不编译 updater 插件、更新命令，也不启动更新或公告轮询；设置提示用户通过 Mac App Store 更新。
- 主程序启用 App Sandbox、网络客户端和用户选择文件的读写权限；Bun Core 单独签名，启用沙盒继承和 JIT。不能给子进程直接套用主程序 entitlements。
- 首版按用户确认采用精简范围：仅 WebDAV 同步，不提供 iCloud、本地文件夹同步和外部 MCP；Core 使用 `--no-mcp`，不申请网络服务端权限。官网版保持原有能力。
- 商店版保存模型连接前弹出第三方数据分享确认，说明接收服务、地址和文章/问题/学习信息范围；按服务地址在本机记录同意，取消时不保存连接和 Key。删除连接可停止后续发送。
- 商店版隐藏站外赞助入口，在设置提供隐私政策链接。
- 不改现有 Core 架构。数据由系统隔离到沙盒容器；不会静默读取或移动官网版数据库。

## 验证范围与后续事项

- 已验证沙盒资源路径、Core 启动、阅读、词典、生词本、文件选择导入、手动备份和 AI 分享同意/取消；真实模型调用、WebDAV 服务端同步、OCR、钥匙串及完整恢复等尚未全部覆盖。
- 后续若恢复本地同步，须实现并验证跨重启授权；恢复 MCP 须另行验证外部启动语义。
- 官网版已有数据的用户授权导入方式；不得假设两个渠道直接共享数据库。
- 商店证书、描述文件与签名校验已完成；重新打包后必须解包验证无 `com.apple.quarantine`，再确认 Apple 完成构建处理。本次构建 2 已通过。
- 隐私政策、隐私标签、素材权利声明、截图及审核资料已完成并提交；等待 Apple 审核结果，按实际反馈补充资料。
