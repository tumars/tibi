> 原型：[首页](../prototypes/home.html) · [阅读器](../prototypes/reader.html) · [生词本](../prototypes/words.html) · [复习](../prototypes/review.html) · [统计](../prototypes/stats.html) · [设置](../prototypes/settings.html) · [任务](../prototypes/tasks.html)；共享样式 [`v2.css`](../prototypes/v2.css)，共享外壳脚本 [`v2-shell.js`](../prototypes/v2-shell.js)，搜索面板 [`v2-search.js`](../prototypes/v2-search.js)，技能目录 [`v2-agents.js`](../prototypes/v2-agents.js)。

## 1. 原则

1. **中性底 + 白色主区**：浅灰底色上放一块白色圆角主区（12px 圆角、1px 细线、无投影、无纹理）。左栏与底色同色，不做色块。
2. **一个强调色 + 一个品牌暖色**：电光蓝只用于焦点、AI 标识（✦）、进度与选中态；狐狸橙（`--warm`）是品牌暖色，只用于吉祥物、庆祝时刻、连续学习圆环和 logo 书签，不用于按钮和状态提示（避免和琥珀色的"学习区 / 等你确认"、赭黄荧光笔混淆）。蓝橙互补，吉祥物捧的书就是电光蓝；主按钮用靛蓝实心（2026-11-02 起，原为墨色；见原则 8）。界面里的彩色只剩荧光笔标注，所以标注最醒目。
3. **大输入框是首页主角**：首页以"今天想读点什么？"输入框为中心，导入 / 问 Tibi / 找文章三种模式切换。
4. **AI 就地出现、按需出现**：词卡贴着单词弹出；右侧面板（总结、生词、Tibi、任务进度）只在需要时滑出，关闭后内容回到全宽。
5. **过程可见**：导入、找文章等多步任务在右侧显示步骤清单与实时日志（借鉴 Manus），完成后给结果卡片。
6. **界面用系统字体，阅读用衬线**：界面跟随系统（SF Pro + 苹方），和菜单栏、系统对话框是同一种声音；Charter 只用于文章正文、标题、书名、词头和原句。
7. **吉祥物带来温度**：藏狐 Tibi 是唯一的角色形象，SVG 与插画按位置分用，见 §7.2；书架默认不放封面，以文字为主；不再使用程序化涂鸦。
8. **扁平，主动作除外**：只有浮层（词卡、菜单、选区工具条）带一层很淡的投影；主按钮和发送键底部有 2px 深靛蓝的厚度（`--accent-deep`，亮 `#2f3fa8` / 暗 `#4e5cb8`），按下时下沉 2px。其他控件继续扁平，选中态的墨色实心也不变。
9. **动效解释状态变化**：时长 0.15–0.55s，小弹簧；`prefers-reduced-motion` 时全部跳过。

## 2. 字体

所有内容类型（技术文档、新闻、小说）使用同一套字体。

| 角色 | 字体 | 说明 |
|---|---|---|
| 界面（导航、按钮、标签、中文释义、助手回复） | **系统字体**：macOS / iOS 上 SF Pro + 苹方，Windows 上 Segoe UI + 微软雅黑，Linux 上 Noto Sans CJK（2026-10-30 起，原为 Geist + 普惠体） | 正文 13.5px、辅助 11–12px、标题 15 / 20px，600 字重，负字距 −0.01em |
| 文章正文、标题、书名、词头、原句 | **Charter**（macOS 自带；其他系统回退 **Charis SIL**，OFL） | 词头、书名 700 字重 |
| 代码、工具调用、任务日志 | **JetBrains Mono** | |
| 阅读设置里的可选正文字体 | Source Serif 4、Geist | 用户主动选择才生效 |

**正式版不打包阿里巴巴普惠体**（2026-10-31 定）：各平台都有自带的中文字体，打包反而要核对 3.0 版许可，许可问题就此不存在。原型里的 `fonts/` 子集只用于在没有苹方的环境里预览，不随软件分发。Charis SIL（OFL）与 JetBrains Mono（OFL）可以随软件分发。

## 3. 色彩

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#f6f6f5` | `#0b0b0c` | 应用底色、左栏 |
| `--surface` | `#ffffff` | `#141416` | 主区、抽屉、卡片、浮层 |
| `--sunken` | `#f2f2f1` | `#1b1b1e` | 统计卡片、分段控件底槽、输入框、引用块 |
| `--hover` | 黑 4% | 白 5% | 悬停 |
| `--line` / `--line-2` | 黑 7% / 12% | 白 8% / 14% | 分隔线 / 描边 |
| `--ink` / `--ink-2` / `--ink-3` | `#18181b` / `#55555c` / `#6b6b74` | `#ededee` / `#a5a5ad` / `#8e8e97` | 三级文字；`--ink` 也是选中胶囊和提示条的底色 |
| `--accent` | `#3d52e0` 靛蓝（原名电光蓝） | `#7d8cf0` | 焦点、AI、进度、选中。2026-10-31 收一档（原 `#3b5bfd` / `#6f86ff`，饱和度 98% → 72%）：色相与 logo 对齐，白底对比度 5.1 → 6.0 |
| `--accent-wash` | 强调色 8% | 强调色 12% | 选中行、进行中的任务步骤、聚焦光晕 |
| 品牌底色（不是 token） | `#2f3fa8` 深靛蓝 | 同 | 只用于 logo 与应用图标的底色。2026-10-31 由电光蓝调深：满版饱和蓝与橙色狐狸脸是互补色，边缘发"跳"、刺眼。它是强调色的深色版，色相相同 |
| `--warm` / `--warm-wash` | `#f5a043` / 橙 14% | `#f7ab55` / 橙 16% | 品牌暖色：吉祥物、庆祝、连续学习圆环、Tibi 头像底色、logo 书签 |
| `--ok` / `--mid` / `--hard` | 绿 / 琥珀 / 砖红 | 提亮版本 | 难度：舒适 / 学习区 / 偏难（总是配文字） |
| `--hl-new` | 蓝色荧光笔 | 同色系降亮度 | 生词 |
| `--hl-1…4` | 赭黄荧光笔，逐级变淡 | 同 | 见过 / 眼熟 / 认得 / 熟悉 |
| `--c-tech` / `--c-news` / `--c-novel` | 浅蓝 / 浅杏 / 浅绿 | 对应深色 | 文章类型的底色：⌘K 结果里的文章图标、开启封面后的占位底 |

阅读页工具条另有"护眼"开关：只在阅读页生效，把主区与底色改为米色；深色主题下打开也按浅色显示，在阅读页切换深浅色会关掉它。

## 4. 形状与布局

- **圆角**（2026-11-02 加大一档，原为 6 / 8 / 12）：三档，token 在 `styles.css`——`--r-s` 8px 小控件、图标按钮、分段项；`--r-m` 10px 按钮、胶囊、标签行、导航项；`--r-l` 16px 主区、卡片、抽屉、浮层。本文下面各组件里写的旧圆角数值以这三档为准，原型 `v2.css` 还没跟上。阅读器正文里的元素不动。首页大输入框 24px 和对话输入框 20px 是例外；不再使用全圆角胶囊。控件高度 30px（小号 26px），导航项 32px。
- **应用框架**：`左栏 248px（折叠 64px）| 主区 | 右侧抽屉 0 / 400px`（首页没有抽屉，发送后主区切换为对话页），都放在浅灰底上，主区与抽屉距窗口边 12px。**桌面窗口最小 960px**（D8）：960–1180px 时左栏自动折叠为图标栏、抽屉收窄到 360px；不再有更窄的断点。 左栏收起后，鼠标悬停左上角 logo 时它变成"展开"按钮（34px 白底描边、图标镜像），键盘 Tab 也能聚焦到；`⌘\` 随时切换。
- **手机壳**（`mobile.html`，D8，2026-10-31 改版 J1–J10）：按 iOS 原生应用的样子做，不沿用桌面的配色与描边（J10）。**颜色**用 iOS 系统色：分组背景 `#f2f2f7` / 深色 `#000`，卡片 `#fff` / `#1c1c1e`，次级填充 `rgba(118,118,128,.12)` / `.24`，文字 `#000`、`#48484d`、`#8a8a8e`（深色 `#fff`、`#c7c7cc`、`#8d8d93`）；强调色仍是品牌靛蓝，按钮填充用 `#3d52e0` / 深色 `#5468ec`（白字）。**卡片**白底、22px 圆角、不加描边。**不用投影**（主按钮和发送键的 2px 厚度除外，原则 8）：层次只靠底色区分，悬浮的标签栏、输入条、导航按钮也只用 0.5px 细线，分段控件选中块只有 1px 的轻阴影。背景不用渐变（试过首页顶部浅靛蓝 + 橙渐变，浅色下发脏，已去掉）。**按钮**全是胶囊：主按钮强调色填充，次按钮系统灰填充，"开始"这类用浅强调色底 + 强调色字。**导航**：各页**不放页标题**（2026-10-31，用户反馈：标签栏已经说明在哪一页），顶栏只留 40px 圆形玻璃按钮（我的深浅色与设置，阅读器的返回与标注说明）；书架顶栏是 40px 高的灰底搜索框（系统次级填充、20px 圆角）加右侧圆形"+"，两者同一行，内容紧接着开始；复习入口页顶部只留 16px 间距。**标签栏**：左边 62px 圆形狐狸（"今天"，选中时外观不变，不加底色和描边），右边悬浮胶囊（距边 14px、高 62px、半透明模糊底）；未选中图标为线条 + 黑字，选中换成实心图标 + 强调色、底下一块系统灰；复习项右上角红色计数。**列表**是 iOS 分组列表：行高至少 52px、16.5px 字，分隔线从文字起点开始；"我"的菜单每行前面一个 30px 彩色圆角方块图标（设置应用的样式）。**首页**没有顶栏和问候，最上面是一行 15px 的今日进度（22px 橙色小圆环 + 今日分钟 + 连续天数，数字黑色加粗、其余次级灰），卡片直接接在下面；输入条与标签栏同样的半透明底，悬浮在标签栏上方，右侧圆钮空着时是"+"（导入），有字时变成强调色发送键；对话里自己的话是强调色气泡，Tibi 的回答是白色气泡。**底部面板**距边 8px、36px 圆角，两档高度（半屏 / 全屏，全屏时贴边），把手可拖。**阅读器**纸面用纯白 / 纯黑，全屏，工具栏也是悬浮胶囊，打开的开关用浅强调色底，滚动时与顶栏一起收起，顶部 2px 阅读进度。**复习**的选项是整行 54px 白色圆角卡片，操作区在下半屏。可点元素最小 44px。小组件用 logo 的深靛蓝渐变底与白字。桌面浏览器里预览时，手机框里模拟状态栏（时间、灵动岛、信号、电池）和主屏指示条，真机上由系统绘制。
- **左栏**：Logo、搜索按钮（无边框，浅色文字 + `⌘K`）、导航（32px 行，当前项浅蓝底 + 蓝字；计数一律灰字，到期 / 待审批只加粗，不做实心徽标）、视页面而定的列表（最近 / 来源文章 / 书架与目录）、底部连续学习圆环（无卡片底）。阅读器默认折叠为图标栏（`⌘\` 切换）。
- **顶栏**（主区内，52px）：左侧是页标题（15px、600 字重；页面正文不再重复大标题），右侧 8px 圆角按钮；开启状态为墨色实心。同一功能只在一处出现：首页的对话入口是大输入框，顶栏不再放 Tibi 按钮；阅读器等没有输入框的页面才在顶栏放 Tibi。

## 5. 组件

- **大输入框**：白底、24px 圆角、1px 描边；聚焦时 1.5px 电光蓝描边 + 6px 浅蓝光晕；拖入文件时整块变浅蓝。底部一行：附件、模式分段控件（白色滑块弹簧滑动）、"快速 / 深入"档位、圆形发送按钮（无内容时淡化）。
- **建议胶囊**：34px 高，细描边，图标 + 文字。
- **统计卡片**：浅灰底、16px 圆角、无描边；数字 28px、600 字重、等宽数字；右上角 64×26 的走势小线（强调色 / 灰 / 绿各按指标），悬停 1.5px 描边表示可点击。
- **文章卡片**：默认无封面——12px 圆角细描边卡片，（书 ·）类型与进度 + Charter 标题（最多三行）+ 开头一句（Charter 斜体，两行）；开启封面时为 16:10 封面 + 标题（最多两行）+ 难度圆点与生词率；悬停时整卡浅灰底；新导入的卡片带电光蓝描边。
- **右侧抽屉**：头部 52px（14px 半粗标题 + 右侧一个 30px 小按钮的专属动作 + 关闭）、可滚动内容；只用于阅读器、生词本、运行记录（D9）。头部不放页签——打开抽屉的那组顶栏按钮就是页签（阅读器的总结 / 生词 / Tibi），避免同一组开关出现两份。
- **书架页工具栏**：34px 圆角筛选框（220px 起）、形态分段控件（全部 / 文章 / 书，浅灰槽 + 白色滑块，计数 11px 灰）、排序下拉（胶囊形、自绘箭头）、网格 / 列表分段控件（30×26 图标按钮）、右侧灰字"封面已关闭"。第二行**标签筛选**：12px 灰字"标签"+ 一排 28px 标签胶囊（`.tagf`，细描边，计数 11px；系统类型用浅灰底无描边 `.sys`，与用户标签之间 1px 竖线隔开；选中为墨色实心），选中后出现下划线灰字"清除"。
- **标签**：卡片上的小标签 `.tagc` 20px 高、6px 圆角、11px 字、浅灰底（系统类型版本为细描边无底色）；卡片最多显示两个，列表视图显示类型 + 两个标签。
- **书卡片**：`.card.book`，标题前一枚 12×14 的书脊小图标；元信息多一项"第 n / N 章"；底部进度条分两段（本章 / 全书，3px，间隔 3px）。
- **导入结果卡的标签建议**："Tibi 建议的标签："+ 26px 标签胶囊（默认选中带 ✓，点一下取消）+ "＋ 自己加" + 灰字说明。
- **卡片菜单**：220–280px、12px 圆角、带投影；"标签"与"类型"两项下方各一排小胶囊（24px）直接点选；"删除"红色，与上面用分隔线隔开。
- **引导页**（`onboarding.html`）：居中卡片 960×600+，左栏 300px 浅灰（Logo、150px 吉祥物、它说的一句话、两步列表——当前步白底描边 + 蓝色序号，完成步墨色打勾），右侧是当前步 + 底部"上一步 / 跳过（下划线灰字）/ 继续"。选项用胶囊（选中墨色实心）；水平自评与模型服务商用四格 / 两格卡片（选中 1.5px 蓝描边 + 浅蓝底）。
- **词汇量测试**：4 列 46px 高的词格（Charter 17px），点亮为浅蓝底 + 蓝描边 + 左侧蓝色对勾圆点；顶部"第 n / 5 组"+ 5px 进度条 + 词频段；结果页大数字 40px（浅灰卡）+ 两张说明卡（按词频的小柱图、Tibi 会怎么用它）+ 手填输入。
- **左栏"最近"**：每行 13px、7px 上下内边距、10px 圆角，前置 14px 灰色线性图标（对话 = 气泡、文章 = 文档），超长省略；当前对话用白底 + 1px 描边高亮（与导航当前项一致）。
- **对话页**（首页发送后，D9）：占满主区；顶栏面包屑"首页 / 导入文章"（"首页"可点）；消息流居中、最宽 760px，用户消息为浅灰气泡靠右（最宽 72%）、Tibi 回复为纯文字 15px，步骤、日志、结果、过程、审批卡最宽 640px；底部输入框 22px 圆角、最宽 808px 居中，下面一行 11.5px 灰字提示"Tibi 会记住这次对话"。
- **任务步骤**：每步一行，左侧圆形状态（空心 / 旋转 / 墨色打勾），进行中的一行浅蓝底，右侧显示耗时；下方为等宽字体日志块。
- **结果卡片**：标题（Charter）+ 元信息 + 总结 + "开始阅读"（主按钮）/"在书架中查看" + 来源标注；开启封面且文章有封面时顶部加封面。
- **标注说明**（阅读器底栏）：统计项前带 10px 圆角色块（生词 = 蓝荧光笔、学习中 = 赭黄渐变、待确认 = 文字本身加铅笔点线），整组可点，悬停浅灰底，末尾一个 16px 的 `?`；点开 440px 宽、16px 圆角的浮层贴在底栏上方：每行"例词（Charter，真实标注样式）+ 名称 + 一句说明"，底部一行灰字补充规则。
- **词卡浮层**：340px 宽、18px 圆角、细描边 + 淡投影；宽屏放在正文右侧页边，与单词同高；空间不足时放在单词下方或上方，并限制高度、内部滚动；窄屏为底部抽屉。"所在句子、翻译与解析"默认折叠。
- **熟练度阶梯**：六格（生词 → 掌握），当前档及之前按标注色填充，下方一句说明；不显示数字。
- **熟练度标签**：小胶囊，底色为对应的荧光笔色。
- **分布条**（生词本）：10px 高，六段按数量占比，段间 3px，悬停纵向放大，点击筛选。
- **左栏视图**（生词本）：三组（视图 / 值得看看 / 不在复习里），每行 14px 线性图标 + 13px 文字 + 右对齐计数（逾期为砖红），当前项白底描边；取代原来的"来源文章"列表。
- **标签行**（生词本）：与书架页相同的 `.tagf` 胶囊行，放在筛选行下方；选中墨色实心，右侧"清除"。

## 7. 吉祥物与插画

### 7.1 吉祥物：藏狐 Tibi（提比）

> 吉祥物、产品名和 AI 助手是同一个角色：和你对话、帮你导入文章、找文章、讲解、出题的就是 Tibi。Tibi 的小头像（`v2-agents.js` 的 `FOX_FACE`，橙色狐狸脸 + 浅橙底）出现在来源标注、过程卡、审批卡、运行记录中。

> 组件 [`v2-fox.js`](../prototypes/v2-fox.js)，展示页 [`mascot.html`](../prototypes/mascot.html)。

- **形象**（2026-10-29 第二版）：可爱风格，参考多邻国 Duo——圆滚滚的一体身形、头大身小、眼睛几乎全是深棕瞳孔（2026-11-02 按设定图重画，原来白眼球多、眼神偏紧张；倾听和惊讶时瞳孔缩小才露出眼白）、饱和的暖橙色、粗短的脚和小爪、腮红；造型原创。保留藏狐的辨识度：上窄下宽的大脸、浅色"方下巴"脸颊、脸颊两侧灰毛、一字形的半垂上眼皮和小眉毛（平时是淡定的眼神，倾听和惊讶时睁大）、灰色体侧、蓬松的尾巴带白尖。扁平色块，无描边、无渐变；眼睛、鼻子、嘴用深棕色。
- **配色**：毛色 `#f5a043`、深一档 `#e3842a`（脚、爪、眼皮线）、脸颊与肚子 `#fff4e2`、体侧灰 `#cfc3b4`、耳内 `#ffc7a6`、腮红 `#ff8f7d`、五官 `#2b1f17`；书本用强调色电光蓝。
- **实现**：内联 SVG + CSS 关键帧动画，零依赖、约 9 KB；状态用 `data-state` 切换，`Fox.mount(el, { state, size, interactive })` 返回 `set(state)` 与 `pulse(state, ms)`（一次性反应后回到原状态）。系统开启"减少动态效果"时静止。
- **状态**：

| 状态 | 表现 | 用在哪里 |
|---|---|---|
| 待机 idle | 半垂眼皮、呼吸、眨眼、尾巴轻摇、偶尔抖耳 | 首页站在输入框上的默认状态 |
| 倾听 listening | 眼睛睁大、耳朵竖起、头微偏 | 输入框获得焦点 |
| 思考 thinking | 歪头、眼睛看右上、气泡点依次闪 | Tibi 在想问题、找文章、讲解 |
| 阅读 reading | 低头捧书、眼睛左右扫、翻页 | 导入、分析文章 |
| 开心 happy | ^ ^ 笑眼、张嘴吐舌、腮红加深、蹦跳、尾巴快摇、星星 | 任务完成、达成目标；点它一下 |
| 睡觉 sleeping | 闭眼低头、慢呼吸、飘 Z | 深夜（23:00–5:00）打开首页；鼠标移上去会醒一下 |
| 惊讶 surprised | 眼睛睁圆、瞳孔变小、耳朵竖、弹一下、感叹号 | 出错、需要你确认（审批卡出现时） |

- **尺寸**：24–240px 都可用；首页 124px。
- **位置**（2026-11-02）：要和界面发生关系，每屏最多一只。首页狐狸站在输入框右上方，脚踩描边，不显示地面阴影；问候靠左，问候语带一笔荧光笔（每屏最多一处）。原型 `v2-fox.js` 还是旧脸。
- **性格**：一本正经的可爱。表情平静，偶尔冷幽默；文案用第三人称，只出现在空状态、完成时和深夜首页，报错不开玩笑（§9）。现有四句：生词本空"罐子还是空的。"、复习完成"n 张，全翻完了。"、里程碑"连续 n 天。Tibi 有点意外。"、深夜"Tibi 睡了，你随意。"；不要再加多，看多了会腻。
- **减少吉祥物**（设置 → 通用，手机在外观与语言；只存本机）：隐藏首页狐狸、空状态和完成页的插画、贴纸与荧光笔标题，上面四句换回直白文案。标签栏的狐狸、Tibi 头像和 logo 不受影响。
- **技术选择**（2026-10-29）：

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| ⭐ SVG + CSS 动画 | 零依赖、体积小、随主题、代码直接切状态、任何尺寸清晰 | 动作复杂度有限（逐帧、骨骼动画难） | v1 采用 |
| Rive（状态机运行时，约 80 KB WASM） | 设计师在编辑器里做骨骼动画和状态机，代码只发输入事件 | 需要会 Rive 的设计师、额外运行时 | 以后有设计师时升级到它，状态名保持一致 |
| WebGL 3D（three.js + glTF 动画） | 立体、可转动 | 体积大（库 + 模型数百 KB）、低端机耗电、与扁平界面风格不搭、建模成本高 | 不采用 |

- **Logo**：`img/logo.svg`，深靛蓝（`#2f3fa8`）圆角方块 + 吉祥物 Tibi 的正脸（橙色方脸、浅色方下巴、大眼睛带高光、腮红），和吉祥物同一套配色；所有页面左栏 26px、7px 圆角，旁边是文字 "Tibi"。也作为应用图标。
- **书架默认不显示封面**（2026-10-29）：卡片只显示类型、进度、标题（Charter）、开头一句（Charter 斜体，两行）、难度与生词率；"继续阅读"、导入结果、找文章推荐同样不放封面。文档的 `cover_path` 字段保留，"设置 → 通用 → 书架显示封面"开启后，有封面的文章（EPUB 自带、网页配图、图像模型生成）才显示；原型里的 `img/cover-*.jpg` 是开启后的示例图。
- **吉祥物插画**（`img/mascot/`，清单见 [`07-mascot-assets.md`](07-mascot-assets.md)）：与 SVG 小狐狸不同框。书架、复习、运行记录、生词本的空状态和复习完成页用插画；首页、手机版首页、引导页要跟着操作切换状态，用 SVG 小狐狸；统计页空状态没有专属插画，也用 SVG。首页失败态用 `error-generic` / `error-offline` 插画。
- **其他位置**：阅读器等处剩余的程序化涂鸦，之后逐步换成吉祥物或同风格插画。

## 8. 动效

|---|---|

| 词卡浮层 | 轻微上浮 + 缩放出现 |
| 标为生词 / 学习中 | 荧光笔从左向右划过 |

## 9. 文案（2026-10-31）

界面文字的目标是"看得懂、不打扰"。写之前先问：删掉这句，用户会不会做错？不会就删。

| 规则 | 做法 | 例子（改前 → 改后） |
|---|---|---|
| 一件事只说一遍 | 输入框占位、按钮、标题已经说清的，不再加副标题或小字 | 首页标题下"粘贴网址或文章、拖入 PDF…"与占位重复 → 删掉 |
| 不解释界面本身 | 开关、选项的名字说清楚了就不加说明；只保留会影响决定的信息（快捷键、代价、范围） | "跟随系统时会随 macOS / Windows 的深浅色自动切换" → 删掉；"每段下方显示中文译文，阅读时按 T 切换" → "阅读时按 T 切换" |
| 不讲实现 | 不在界面上出现 FSRS、钥匙串、子任务并行、置信度这类词；需要时收进"查看过程" | "FSRS · 目标记忆保持率 90%" → "目标记得率 90%" |
| 不安抚、不打气 | 不写"没关系""不用紧张""不错""随时能改""Tibi 会自己判断" | "没关系，记住它" → "✕ 选错了"；"不用紧张，这不是考试" → "只点确定认识的词" |
| Tibi 少用第一人称 | 吉祥物开场可以说"你好，我是 Tibi"，之后不写"我来帮你""我已用 AI 标出"；结果直接给 | "按你的水平挑了两篇，第一篇最适合今天：" → "找到两篇：" |
| 报错三段式压成两句 | 第一句说发生了什么，第二句说能做什么；不重复"不受影响的功能"清单 | "网络断了，或者 DeepSeek 暂时不可用。总结、讲解和出题要等恢复后才能用；书架里的文章……" → "总结、讲解和出题暂时用不了。阅读、查词和复习不受影响。" |
| 空状态一句话 | 标题 + 最多一句说明 + 动作；说明只讲"怎么开始"，不罗列这里将来会出现什么 | 运行记录空状态 → "Tibi 做的事和需要你确认的改动会出现在这里。" |
| 不加表情和感叹号 | 不用 🙂、！、～；破折号只在确实需要停顿时用 | "先别急着看答案 🙂 提示一下：……" → "提示：看它前后的词，它在句子里是什么成分？" |
| ✦ 只标 AI | ✦ 用在问 Tibi 的入口和 AI 生成的内容上，不当装饰；设置里的选项不加 | 题型开关"✦ 造句" → "造句" |
| 词要统一 | 同一件事全站一个叫法：记得率（不叫记忆保持率）、重练（不叫再见一面）、选择要做的事（`/` 菜单） | — |

原型里的"（原型）……正式版会……"和"原型演示"开关是评审用的说明，不受这些规则约束，正式版删除。
