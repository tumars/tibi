# 18 · Design System & UX 文案规范

> 本文档定义 Tibi 桌面端、菜单栏托盘与本机分发管理台的 **Design Token 体系**、**语义化组件库与 Do / Don't 范例**，以及 **UX 文案规范**，确保产品界面风格连续、信息克制、消除模板化「AI Slop」观感。

---

## 1. Design Token 体系

唯一真源位于 `apps/desktop/src/tokens.css`（分发管理台独立维护同结构变量于 `admin/ui/style.css`）。所有页面与组件 **禁止硬编码离散色值、圆角或非 4px 倍数间距**。

### 1.1 表面与文字层级（四套主题统一）

覆盖 Light、Auto Dark、Explicit Dark 与 Sepia（阅读纸面）四套主题：

| 分类 | Token | 语义用途 |
|---|---|---|
| 表面 | `--bg` / `--surface` / `--sunken` / `--paper` | 画布底色 / 卡片与弹窗表面 / 嵌套凹槽 / 阅读纸面 |
| 边框 | `--line` / `--line-2` | 常规分割线 / 强调边框与聚焦态外框 |
| 墨色 | `--ink` / `--ink-2` / `--ink-3` | 正文与标题 / 次要信息 / 辅助标签与占位符 |
| 品牌 | `--accent` / `--accent-fill` / `--accent-wash` | 链接与选中文字 / 主操作填充 / 选中底色 |
| 四态语义 | `--info` / `--ok` / `--mid` / `--hard` + `*-wash` | 提示 / 成功 / 警告 / 危险（含浅底色） |

### 1.2 间距体系（严格 4px 倍数）

所有 `padding`、`margin`、`gap` 均来自 4px 基数标尺：

- 基础标尺：`--sp-0 (0)`、`--sp-1 (4px)`、`--sp-2 (8px)`、`--sp-3 (12px)`、`--sp-4 (16px)`、`--sp-5 (20px)`、`--sp-6 (24px)`、`--sp-8 (32px)`、`--sp-10 (40px)`、`--sp-12 (48px)`。
- 语义层级：
  - **元素内部（控件与图标/文字）**：`--sp-1` ~ `--sp-2`（4px–8px）
  - **同组并列项**：`--sp-2` ~ `--sp-3`（8px–12px）
  - **卡片/面板四边内边距**：`--pad-card (16px)`、`--pad-card-lg (24px)`，嵌套容器保持**上下左右等距对称**
  - **模块分区间距**：`--gap-sec (24px)` ~ `--sp-8 (32px)`

### 1.3 圆角体系与等距内缩（Concentric Radius）

嵌套圆角遵循 **等距内缩公式** `r_inner = max(0, r_outer - inset)`，避免内外弧度视觉打架：

| Token | 值 / 公式 | 典型场景 |
|---|---|---|
| `--r-xs` | `4px` | 代码片段、高亮标记、迷你标签 |
| `--r-s` | `6px` | 小按钮、徽章、紧凑下拉项 |
| `--r-m` | `8px` | 常规按钮、输入框、分段控件外壳、列表行 |
| `--r-l` | `12px` | 常规卡片、设置分组、提示框 |
| `--r-xl` | `16px` | 大卡片、弹窗、抽屉 |
| `--r-2xl` | `20px` | 首页主视觉卡、引导卡片 |
| `--r-pill` | `999px` | 胶囊筛选器、开关轨道、圆形图标按钮 |
| `--r-in-m-1` | `calc(var(--r-m) - 2px)` | 分段控件（`--r-m` 内缩 2px）内部选项 |
| `--r-in-l-1` | `calc(var(--r-l) - var(--sp-1))` | `12px` 容器内缩 `4px` 的子元素 |
| `--r-in-l-2` | `calc(var(--r-l) - var(--sp-2))` | `12px` 容器内缩 `8px` 的子元素 |
| `--r-in-xl-2` | `calc(var(--r-xl) - var(--sp-2))` | `16px` 弹窗/面板内缩 `8px` 的子卡片 |
| `--r-in-2xl-4` | `calc(var(--r-2xl) - var(--sp-4))` | `20px` 大卡内缩 `16px` 的内嵌块 |

**连续圆角渐进增强**：在支持 `corner-shape: squircle` 的引擎中，仅对**圆角矩形**（卡片、按钮、弹窗、面板、提示气泡）启用连续圆角；圆形、胶囊与 2px 进度条保持标准圆弧。

## 2. 语义化组件库与 Do / Don't 范例

核心原语统一收口在 `apps/desktop/src/components/ui/`：

| 组件 | 语义职责 | 关键变体 / 属性 |
|---|---|---|
| `Button` (`.btn`) | 触发动作 | `.pri`（页面唯一主动作）、`.soft`（列表行次级强调）、默认（次级）、`.danger`（破坏性）、`.linkbtn`（轻量行内） |
| `Badge` | 只读状态/元信息标识 | `neutral` / `accent` / `ok` / `warn` / `danger` / `outline` |
| `Chip` (`.chip`) | 可切换的筛选条件 | `.on` 表示激活态 |
| `SegmentedControl` (`.seg`) | 2–4 项单行互斥模式切换 | 禁止换行、禁止超过 4–5 项 |
| `StageBar` | 6 档词汇熟练度阶梯选择 | 专用于词条 `0..5` 状态 |
| `InfoTip` (`ⓘ`) | 低频说明、计算口径、快捷键提示 | **默认隐藏**，悬停/点击弹出，支持 `Escape` 关闭与视口防溢出 |
| `Alert` | 页面/模块内的实时状态或前置缺省提醒 | `info` / `success` / `warning` / `danger` + `compact` |
| `Empty` | 空列表 / 无筛选结果 / 加载失败占位 | **仅一句话 + 至多一个操作按钮**（错误态可附 `detail`） |
| `SettingItem` | 设置项标准行 | 标题（纯文本 `.t`）、`badge`、`tip`（`ⓘ`）、动态 `status` 与右侧控件 |
| `SectionHeader` | 区块标题栏 | 标题 + 可选 `InfoTip` + 键值摘要 `meta` + 右侧动作 |
| `PageFooter` | 页脚免责声明与更新时间 | **每页仅出现一次**，位于页面底部 |

### Do / Don't 范例

#### 1) 多档位选择器 vs 分段控件
- **Don't**：在窄抽屉中用 `.seg` 强行 `flex-wrap: wrap` 塞入 6 个词汇熟练度档位，破坏分段控件的单行互斥语义。
- **Do**：单行 2–4 项用 `.seg`；6 档熟练度使用专用的 `<StageBar>`。

#### 2) 按钮层级克制
- **Don't**：在电台剧集列表的 30 行里全部使用高亮主按钮 `.btn.pri`，造成整屏蓝色噪声；或在确认删除/清空弹窗中用蓝色 `.btn.pri`。
- **Do**：单页仅保留 1 个主 CTA 用 `.btn.pri`；重复列表行动作使用 `.btn.sm.soft` 或默认按钮；删除、清空、移除类破坏性动作统一使用 `.btn.danger` / `.linkbtn.danger`。

#### 3) 静态解释 vs 实时告警 vs 提示气泡 `ⓘ`
- **Don't**：在每个模块标题下方放一行常驻说明文字，或在电台/发布/公告页顶部常驻大段教程横幅（`.radio-tip`、`.section-note`）。
- **Do**：
  - 实时阻塞状态或错误（如 RSS 拉取失败、未配置模型导致功能不可用）使用 `<Alert tone="warning|danger">`。
  - 低频说明、规则口径与使用技巧统一折叠进 `<InfoTip>`（`ⓘ`），默认不占用版面。

#### 4) 状态标签 vs 筛选胶囊
- **Don't**：把只读状态（如「播客」「已缓存」「默认」「已关闭」）做成带边框可点击外观或散落的内联样式 `<span>`。
- **Do**：只读状态使用 `<Badge tone="...">`；可切换筛选条件使用 `.chip` / `.chip.on`。

#### 5) 空状态
- **Don't**：写主标题 + 俏皮话 + 长段落解释 + 多个并排按钮。
- **Do**：使用 `<Empty title="一句话说明当前状态。" action={<button ...>明确动作</button>} />`，且区分「真为空」与「筛选/搜索无结果」（后者提供「清除筛选」按钮）。

## 3. UX 文案规范

1. **禁止复述型副标题**：标题已经说明模块定位时，不配一句换说法重复它的副标题（如首页、引导页、分发管理台 `<h1>` 下方）。
2. **禁止逐模块堆砌说明**：保留核心标题与关键键值对（如版本号、数量、时长、最后同步时间），删除每个模块下的常驻说明文字。
3. **免责声明与更新时间只出现一次**：集中放在页脚 `<PageFooter>`（如统计页 AI 洞察口径与更新时间、设置页本地存储与实时保存声明、管理台签名验证提示与刷新时间）。
4. **按钮只写动作**：使用清晰的动宾短语（如「查看语境释义」「上传文件」「校验产物」「推送公告」），禁用「点击按钮即可……」「点一下看……」等口语化提示。
5. **空状态极简**：只写一句话，配一个明确的下一步操作按钮。
6. **低频解释进 `ⓘ`**：必要的方法说明、权限规则、计费与隐私口径放进 `InfoTip` 提示气泡，默认隐藏，使用规范书面语，避免营销口吻或拟人口语。
