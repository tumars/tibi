## 1. 参考与借鉴

| 产品 | 值得借鉴的地方 |
|---|---|
| **Agenda** | 分栏但几乎没有边框，靠留白和柔和的底色区分区域；侧栏像半透明的纸垫；排版松弛、呼吸感强 |
| **Drafts** | 文字优先，界面元素在书写时几乎消失；功能藏在需要时才出现的位置 |
| **Bear** | 以排版为核心卖点，有自己的字体、细腻的主题系统；"克制的暖色 + 精确的字重层级" |
| **iA Writer** | 为阅读距离设计的字体；Focus Mode 只突出当前句；工具栏只显示当前语境需要的东西 |
| **Things 3** | 细节精致：柔和阴影、圆角、动效都极其克制；没有"多余的线" |

**v0.1 为什么显得商务**：处处是 1px 边框和圆角卡片、分段控件和标签胶囊、无衬线 UI 字体加大写字母小标题、冷灰底色——这些是中后台/SaaS 的语汇。

## 2. 原则

1. **一块色、两张纸**：左栏是深色色块（导航）；中栏和右栏是放在同一张"桌面"上的两张纸（阅读 / 词卡·总结·助手），结构完全一致：桌面上的顶栏 → 纸面 → 桌面上的页脚，纸的上沿、下沿对齐。三栏不用边框；纸内不用卡片套卡片。
2. **墨色分层 + 品牌色呼应**：文字只用三级墨色 + 强调色"蓝黑墨水"（✦ AI 标签、短语线、输入框聚焦）。**品牌色 = 左栏颜色**，在右栏只出现在两处：选中的标签滑块、发送按钮——让左右两栏在颜色上呼应。不使用渐变、光晕、半透明。
3. **标注像真的笔迹**：生词像**荧光笔**涂过（色带只覆盖字的下半部分）；学习中是**赭黄荧光笔**、熟练度越高越淡；待确认是**铅笔虚线**；短语是**钢笔下划线**。
4. **一种字体贯穿全页**（v0.7 起，Kami 方案）：英文 Charter、中文阿里巴巴普惠体，正文、标题、界面文字都用这一套字体，层级靠字号、字重和间距区分；标签用常规大小写的小号字，不用全大写、不用斜体；不使用首字下沉、装饰符号等书籍化处理。（v0.3–v0.6 为"正文衬线、界面无衬线"。）
5. **扁平，不用投影**：窗口、纸面、浮层、提示条都不用投影，只用 0.5–1px 细线与底色差区分层级；纸面保留约 2–4% 不透明度的噪点纹理（暗色模式同样保留），不做卷边等拟物处理。
6. **控件去"控件感"**：状态选择用一排"墨点"而非分段按钮；标签页用文字 + 小圆点而非下划线 Tab；按钮以文字按钮为主，只有一个主操作用实心墨色。
7. **动效有意义**：动效只用来解释状态变化（标注变化、卡片切换、消息到达），时长 150–550ms，弹簧回弹小；尊重系统"减少动态效果"设置，此时全部跳过。详见第 6 节。

## 3. 字体

**所有内容类型（技术文档、新闻、小说）使用同一套字体。**

### 3.1 当前方案（v0.8）

英文沿用 [Kami](https://github.com/tw93/kami) 的 Charter；中文用阿里巴巴普惠体 3.0。全页（正文、标题、界面）只用这一套字体，层级靠字号、字重和间距区分。

| 角色 | 字体 | 来源 / 许可 |
|---|---|---|
| 英文（正文、标题、界面） | **Charter** | macOS 自带；其他系统回退到 **Charis SIL**（基于 Charter 的开源字体，OFL，Google Fonts） |
| 中文（释义、助手、界面） | **阿里巴巴普惠体 3.0**（55 Regular / 65 Medium） | 官方声明全球免费商用 |
| 代码 | **JetBrains Mono** | OFL |
| 阅读设置中的可选正文字体 | Source Serif 4、Geist | OFL |

**普惠体的分发注意事项**：官方声明免费商用，但早期（1.0）版权声明曾限制"未经授权上传、转载字体文件"和修改字体。正式版在打包普惠体（以及做子集化以减小体积）之前，需要核对 3.0 版许可原文（[fonts.alibabagroup.com](https://fonts.alibabagroup.com)）；如不允许随软件分发，则改为首次启动时从官方下载。

原型使用的是普惠体的**子集**（只含原型用到的约 760 个字），优先使用本机已安装的普惠体，见 `docs/prototypes/fonts/README.md`。

> v0.7 曾试用 Kami 的中文字体仓耳今楷（TsangerJinKai02），因"个人非商用免费、商用需授权"与 MIT 开源冲突，已放弃。

### 3.2 上一版方案（v0.3–v0.6）

| 角色 | 字体 |
|---|---|
| 英文正文、标题、词头、原句 | Source Serif 4 |
| 界面文字、标签、中文释义、助手回复 | Geist + 思源黑体 |
| 代码 | JetBrains Mono |

## 5. 组件要点

- **窗口**：无边框圆角窗口，桌面色底；顶栏透明，标题用小号无衬线居中。
- **书架侧栏**：条目只有标题 + 一行元信息（类型、难度圆点）；当前项是一张浅纸片，不用描边。
- **阅读纸面**：居中版心约 64 字符宽，纸面有轻微纹理，用细线勾边、无投影；标题用正文衬线体 600 字重；眉题为小号无衬线。
- **阅读开关**（中栏顶栏左侧，胶囊开关，开启时填充品牌色）：**译文**（每段下方显示中文译文，左侧一条细线，快捷键 T）、**行间释义**（在生词、学习中的词和学习中的短语上方以小字显示简短中文释义，行距相应加大，快捷键 G）。
- **右栏**：与中栏同构。顶部（与中栏标题栏同高）是胶囊形分段控件（词卡 / 总结 / 助手 / 生词），品牌色滑块随切换弹簧滑动；下面是一张纸，上沿与中栏纸面对齐；底部页脚与中栏页脚同一行，显示当前助手后端与记忆条数。
- **词卡**：直接排在纸上（不再套卡片）：词头用衬线体 600 字重，音标斜体，词典释义用编号列表；AI 内容用蓝黑色"✦ AI"标签标识。
- **熟练度**：一条六格阶梯（生词 / 见过 / 眼熟 / 认得 / 熟悉 / 掌握），当前档及之前的格子按各自的标注色填充，下方一行文字说明当前档的含义；不显示数字。
- **左栏导航**（首页）：图标 + 文字，当前项为浅色块，右侧是数量；底部用户卡片。
- **指标条**（首页今日四项）：一条上下细线包住，项与项之间竖向细线分隔，不做卡片；数字用正文衬线体 600 字重，单位为小号无衬线。
- **书架卡片**：纸面底 + 0.5px 细线描边，悬停时描边加深；左上角类型色点（技术文档蓝、新闻赭、小说绿，只做标识，不做大面积色块）；标题衬线体最多 3 行；底部难度、生词率、进度条。
- **小折线**（已掌握词数）：单序列，只用强调色，2px 线 + 10% 面积填充 + 终点圆点，无图例和坐标轴，悬停显示当日数值。
- **分布条**（生词本熟练度）：一条 10px 高的分段条，按"生词 → 掌握"固定顺序、各段用对应的标注色，段间 2px 间隔；下方带色块的文字标签直接标出数量（不另设图例）；悬停显示含义，点击筛选，筛选时其他段降低不透明度。
- **数据列表**（生词本）：行高约 54px，行间细线分隔，无斑马纹；选中行用强调色浅底；勾选框为圆角小方块，选中填品牌色；批量操作时底部浮出深色胶囊操作条。
- **滚动条**：使用 **OverlayScrollbars**（MIT）实现覆盖式滚动条，三个平台表现一致：滚动时出现、停止约 0.9 秒后自动隐藏，不占版面宽度；圆角细滑块（可视约 4px，悬停 / 拖动时约 6px 并加深），无轨道，上下各留 8px 避开纸面圆角；左栏深色块上用浅色滑块；可点击轨道跳转。库加载失败时退回原生细滚动条（同样的颜色与圆角）。主题见原型中的 `.os-theme-lexi`。
- **助手**：回复为无衬线正文；用户消息是浅灰气泡；建议问题是浅灰胶囊；输入框为浅灰胶囊，聚焦时变白并出现蓝黑细描边；发送按钮为品牌色圆形；工具调用显示为细线框的小卡片，用等宽字体。

## 6. 手绘强调（Rough Notation）

**原则**：基础标注（生词、学习中、待确认的色带与虚线）始终用 CSS，保证全篇几百个词也流畅；手绘标注只用于少量**强调时刻**，数量保持在十几个以内。颜色用蓝黑墨水 `--accent`，笔画 1.3–2px。

| 场景 | 手绘效果 | 关闭"手绘风格"时 |
|---|---|---|
| 短语 | 手绘下划线，打开文档后依次画出 | CSS 直线下划线 |
| 选中单词 | 手绘圈注 | CSS 细线框 |
| 选中短语 | 手绘左右括号；跨行时改为双层手绘下划线 | 浅色底 |
| 标为生词 / 学习中 | 先用对应颜色的手绘荧光笔涂一遍（最多 6 处，依次），再交还给 CSS 色带 | CSS 色带从左向右划过 |
| 跳转定位（生词列表、短语列表） | 手绘方框闪现 2 秒 | CSS 闪框 |
| 读完 → 回顾本篇重点 | 依次圈出仍在学习的短语和生词（最多 12 个），数秒后消失 | — |

**实现约束**：
- 圈注和方框在元素跨行时会被拆成每个词一个，所以跨行元素一律改用加粗的手绘下划线。
- 文档切换后要等入场动画和字体加载结束再绘制，否则位置会算错。
- 译文 / 行间释义开关、字号 / 行距 / 字体 / 主题变化后需要重绘（库只会在窗口尺寸变化时自动重绘）。
- `prefers-reduced-motion` 时不播放绘制动画，直接显示。

## 7. 动效

**库：Motion**（motion.dev，原 Framer Motion，MIT）。正式版用 React 绑定 `motion/react`，原型用其原生 JS 版本（`Motion.animate / stagger`）。选择理由见 [技术选型 §9](../../research/03-tech-survey.md#9-动效库)。

**参数约定**：常规过渡 0.25–0.55s，缓动 `cubic-bezier(.22,.8,.24,1)`；弹簧 `bounce 0.18–0.3`；列表错峰 30–60ms；`prefers-reduced-motion` 时全部跳过；库加载失败时界面照常工作，只是没有动效。

| 场景 | 动效 | 想表达什么 |
|---|---|---|
| 标为生词 / 学习中 | 荧光笔色带**从左向右划过**，同一个词的多处出现依次划过 | "我刚在这些地方做了标记" |
| 标为已知 / 忽略 | 色带**向右收起**后消失 | 标记被擦掉 |
| 读完本篇 → 全部标为已知 | 全文剩余标注**波浪式依次收起** | 一次性的进度感 |
| 撤销 | 恢复的标注重新划过 | 撤销生效的位置 |
| 切换词 | 词卡轻微上浮出现，卡内各段错峰淡入 | 内容已更新 |
| 设置学习状态 | 选中的墨点弹一下 | 确认点击 |
| 切换标签页 | 分段控件的品牌色滑块弹簧滑动并改变宽度 | 位置关系 |
| 助手消息 | 三个蓝黑圆点跳动表示思考中；新消息上浮出现，段落错峰 | 对话节奏 |
| 切换文档 | 纸面淡入上移，段落错峰出现；左栏条目首次加载错峰滑入 | 场景切换 |
| 页脚计数 | 生词 / 学习中 / 待确认数字滚动到新值 | 数字变化 |
| Toast / 选区工具条 | 弹簧弹出 | 临时浮层 |
| 朗读 | 当前句高亮平滑移动（CSS 过渡） | 跟读位置 |
