# Tibi 使用指南

> 面向使用者。开发者看 [开发说明](../dev/README.md)；设计细节看 [00 概念设计](../design/00-concept-design.md)。

## 1. 第一次打开

1. 从 [Releases](https://github.com/tumars/tibi/releases) 下载安装，GitHub 打不开时用 [README](../../README.md#安装) 里的国内下载（未签名版本：macOS 右键 → 打开；Windows SmartScreen 选"仍要运行"）。
2. 引导页问你怎么称呼你、平时常读什么（找文章时用）。Tibi 不测你的水平，也不替你猜哪些是生词：读的时候点不认识的词，标成生词或加进生词本就行。
3. 读第一篇：选一篇内置示例，或粘贴一个英文网址。

## 2. 连接模型

首次引导里就会让你连模型；没连时每次打开 Tibi 也会先问一次，可以选"先不连"。不连模型也能读、查词典、复习、看统计。要用总结、语境释义、译文、对话、批改这些 AI 功能，需要连一个模型：

- **设置 → 模型 → 添加**，或在引导页的"连接模型"一步。
- 默认推荐 **DeepSeek**：去 [platform.deepseek.com](https://platform.deepseek.com/) 创建 API Key，粘进来，点"测试连接"。
- 其他服务选"自定义"，填 OpenAI 兼容接口的 Base URL 和模型名。可以分"快速"和"深入"两档：日常讲解用快速档，长文分析、批改用深入档。
- API Key 存在应用数据目录的 `secrets.json` 里，不进数据库，也不进 Tibi 的备份和同步。文件没有加密（Android 除外）。
- **每月预算**（设置 → 高级）：超出后 AI 任务改为"稍后补做"，下个月或调高预算后自动补上。

## 3. 导入

首页输入框会自己判断：

- 粘贴**网址** → 导入网页正文；
- 粘贴一大段**英文** → 导入这段文字；
- 其他 → 当作问题发给 Tibi。

点输入框左边的 **+** 可以选文件：**EPUB**（书，按章节）、**PDF**、**Word（.docx）**、**图片**（拍的书页、截图）。扫描版 PDF 和图片走本地 OCR，第一次用会下载约 10 MB 的英文语言包。也可以把文件直接拖进窗口。

导入在后台进行，左下角和运行记录页能看到进度。连了模型时会顺带生成总结、短语、长难句和阅读建议。

**订阅（RSS）**：侧栏「订阅」里放着你订阅的英文博客和杂志，新文章会自动出现，侧栏上是未读数。点 **加订阅** 贴网站地址就行（也可以贴 RSS / Atom 地址），Tibi 会自己找订阅地址，可以顺便填个分组。每篇文章：

- **点卡片**：用阅读器打开，查词、标生词、总结、问 Tibi 都和书架里的文章一样，但**不会放进书架**；想留着就在阅读器右上角点「加入书架」。
- 鼠标移到卡片上，右下角会出现：**加入书架**（放进书架，先不打开）、**×**（不感兴趣，可以撤销）、在浏览器里打开原文。已经在书架里的标着「在书架里」。
- 滚过去的文章自动标为已读；右上角可以全部标为已读、手动刷新。文章多了在底部翻页。
- **管理订阅** 里可以改名、改分组、开关、删除订阅，看哪个源刷新失败了；也能关掉自动刷新（默认 Tibi 开着时每 30 分钟看一次）。
- 自带 Hacker News、News in Levels（同一条新闻分三档难度）、The Conversation 三个源，不想要可以关掉或删掉。「找文章」会先从你的订阅里挑。

**浏览器剪藏**：Release 里附带 `tibi-clipper-x.y.z.zip`。解压后在 Chrome / Edge 的扩展页打开"开发者模式"→"加载已解压的扩展程序"选这个目录。在网页上点插件按钮（或 Alt+Shift+T）就会把网址发给 Tibi，Tibi 弹出确认后才抓取。

## 4. 阅读

- **颜色**：只有你标过的词才着色——荧光底色是生词，越熟颜色越浅；没标过的词不着色。
- **点一个词**：词卡显示"在这句里"的意思（连了模型时实时生成）、词典释义、音标；点喇叭发音。下面六格是熟练度（生词 → 掌握），点一下就标上（没标过的词点"生词"就加进生词本）；"忽略"表示这个词不用学（人名、术语）。
- **选中一段**：可以"问 Tibi"，在右侧面板里讲解这段。
- **底部工具栏**：译文（整篇对照翻译）、释义（生词上方显示中文）、朗读、全部标注 / 只标生词 / 纯净阅读、读完了。
- **总结**：右上角，看这篇的总结、短语、长难句和阅读建议。
- **Tibi**：右上角，打开右侧面板直接问。
- **朗读**：全文朗读时当前句高亮跟随；可调倍速、单句循环、句间停顿。设置 → 通用 → 朗读引擎可以换成更自然的 Kokoro（第一次下载约 92 MB）。
- **读完了**：记下这一章读完了，不改任何词的熟练度。

## 5. 生词本

你标成生词 / 学习中的词都在这里。可以按今天到期、难词、已掌握等筛选，搜索单词和释义；点一个词看它在你读过的哪些句子里出现过、复习记录。

右上角菜单：**导出**（CSV、Anki）、**导入**（一份已知词表：直接标成已知；一份要学的词表：加进生词本）。

**词典**：左栏"词典"（手机在"我"里）主动查词，不用联网，也不用连模型。可以输入变形（went）、中文（苹果），拼错了会提示相近的词。词条下面列出这个词在你读过的文章里出现的地方。查词不会改熟练度，点"加入生词本"才会进复习。 常用词还有辨析、中译例句、搭配、近反义词和词族（来自词光，AI 生成，未逐条审校），以及英文义项和同义词（来自 Open English WordNet）。

## 6. 复习与练习

- **复习**：每天到期的词。题目用的是你读过的原句：填空、选义、识别（看句子想意思，空格翻面，再按 1–4 自评）。
- 键盘：**Enter** 提交 / 下一题，**空格** 翻面，**1–4** 评分（忘了 / 模糊 / 记得 / 轻松），**P** 朗读句子，**Z** 撤销上一题。
- 中途退出会记住进度，下次接着来。做错的词最后可以"再练一遍"（不计分）。
- **练习**（复习页右上切换）：听写、拼写、易混词、造句（连了模型时 Tibi 批改）。练习不影响复习排期。
- 设置 → 学习与复习：每天最多新学多少词、目标记得率（越高复习越频繁）、是否出识别题。

## 7. 统计

已掌握的词（复习到掌握、或你标为已知的）、每日阅读时间、接下来的复习量、复习表现、学习日历、各类材料读了多少。连了模型时，Tibi 会在顶部写一段观察和建议。

## 8. 和 Tibi 对话

在首页输入框直接问，或者在阅读器里打开 Tibi 面板。Tibi 知道你的水平、正在读什么、最近学了什么，可以：

- 讲解词、句子、语法，比较近义词；
- **找文章**：比如"推荐一篇 10 分钟的科技新闻"——从你的文章来源里挑，回答里的链接点一下就导入；
- 用你这周的生词写个小故事、出几道题；
- 帮你记住一件事（"以后讲解少用术语"）、改一个词的熟练度。

输入 **/** 可以选要做的事。

**权限模式**（设置 → 通用）：Tibi 要写入数据前要不要先问你——每次都问 / 标词自动、其余问 / 全部自动。读过网页内容的任务写入时一律先问。花费上限、技能附加指令、批量删除不管哪一档都每次问。

**让 Tibi 帮你改**：可以直接说"叫我老张"、"语速快一点"、"把这几篇文章归档"、"预算改成 30"。改完回答下面有撤销。API Key、服务商、权限模式这些 Tibi 改不了，它会给你一个去设置页的入口。

**找文章**：Tibi 找到后给一张卡片，勾选想读的点确定就开始导入；不满意就在卡片上直接说要什么。这张卡片一直留在对话里，不用马上回答；接着聊别的，它就作废了。

**运行记录页**：Tibi 在后台做的每件事（导入、分析、对话、出题……）都在这里，能看步骤、用量和花费，可以暂停、取消、重试。快捷键 J / K 上下移动，Enter 打开，Esc 关闭。

**记忆**（设置 → 记忆）：Tibi 记住的关于你的事，可以查看、删除、全部清空，或暂停记忆。

**Tibi 能做的事**（设置 → 高级）：每个技能用快速还是深入档、写入前是否每次都问、附加要求；找文章的文章来源也在这里管理。

## 9. 让其他 AI 工具用 Tibi（MCP）

设置 → 高级 → 其他 AI 工具，打开后按页面上的片段配置：

- Claude Code：复制 `claude mcp add tibi -- …` 那一行在终端运行；
- Codex：把 `[mcp_servers.tibi]` 那段加到 `~/.codex/config.toml`。

这些工具可以读你的学习进度、正在读的文章、生词；写操作（加生词、改熟练度等）要在这里逐项打开，执行时还会按权限模式请你确认。Tibi 要开着才能用。

## 10. 数据

设置 → 数据：

- **自动备份**：每天一次，保留最近 7 份；也可以手动备份。
- **恢复**：回到某个备份的状态；恢复前会先把现在的数据再备份一份。
- **导出学习汇总**：只有计数（导入了几篇、复习了几次等），不含单词和正文；先给你看全部内容，你决定要不要发给作者。
- 生词的导出 / 导入在生词本右上角（见第 5 节）。
- 想彻底清空：退出 Tibi，删掉下面的数据目录（建议先手动备份一份）。

- **同步**（和手机、其他电脑）：开启后选位置——Mac 上的 **iCloud Drive**（需要正式签名版本）、任意**文件夹**（Dropbox、OneDrive、NAS 挂载等，几台电脑都指向它）、或 **WebDAV**（坚果云、Nextcloud、群晖；填地址、账号和应用密码）。先"检查"：那里已有 Tibi 资料库就"加入"，两边的数据合并、不覆盖；没有就"新建"。之后启动时、每 5 分钟、改动后半分钟自动同步，也可以"立即同步"。同步文件不加密；API Key 不同步，每台设备各自填。

数据目录：macOS `~/Library/Application Support/app.tibi/`，Windows `%APPDATA%\app.tibi\`，Linux `~/.local/share/app.tibi/`。

## 11. 快捷键

| 键 | 作用 |
|---|---|
| ⌘K / Ctrl+K | 搜索文章、生词、对话、设置和操作；查不到的英文单词显示词典释义，回车加入生词本；⌘↵ 直接问 Tibi |
| ⌘\ / Ctrl+\ | 收起 / 展开左栏 |
| 复习：Enter / 空格 / 1–4 / P / Z | 提交、翻面、评分、朗读、撤销 |
| 运行记录页：J / K / Enter / Esc | 上下、打开详情、关闭 |
| 浏览器：Alt+Shift+T | 剪藏插件：发送当前网页 |

## 12. 常见问题

- **为什么文章里没有标生词**：Tibi 只标你自己标过的词。读的时候点不认识的词，在词卡上点"生词"就行；认识了就点"掌握"或"其实认识"。
- **AI 功能提示"连接模型"**：见第 2 节。提示"预算"时到 设置 → 高级 调高每月预算。
- **网页导入失败**：有些网站需要登录或拦截了程序访问。可以在浏览器里全选正文复制，粘到首页导入。
- **扫描件识别不准**：OCR 对清晰、正面拍摄的页面效果最好；识别后可以在阅读器里照常查词。
- **界面换成英文**：设置 → 通用 → 界面语言。想让 Tibi 用英文讲解，直接在对话里跟它说。
- **数据会上传吗**：不会，见 [隐私说明](../../PRIVACY.md)。
