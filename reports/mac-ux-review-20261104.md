## 1. 总评

主流程能走通：引导 → 读示例 → 点词 → 进生词本 → 复习 → 统计，整体质感也不错，衬线正文、留白、配色都克制，深色模式完成度高，词典页（变形识别、"在你读过的文章里"的例句）是亮点。

问题主要有三类：

1. **说法和实际对不上**：引导页说"示例不连模型也能看完整效果"，可译文点了就要连模型；第一次复习却提示"上次复习到一半"；统计页"阅读 0 词"旁边就是"文学 118 词"。这类问题最伤信任。
2. **小窗口下布局会坏**：生词本"释义"列被挤成一个字宽，订阅文章的标题是一整串 URL，横向溢出；"回到开头"盖住了对话输入框。
3. **入口重复、信息太满**：今日阅读进度在三处出现；深浅色在两处切换；复习 / 练习既在顶栏切换，又在页面里列一遍；订阅一进来就是红色角标 40。另外界面上露出不少内部说法（R6、"不是模型驱动"、zk · gk）。

## 2. 问题清单

严重度：**P1** 影响信任或挡住使用 · **P2** 明显不好用 / 不好看 · **P3** 打磨

### P1

#### P1-1 引导页承诺"不连模型也能看完整效果"，进去后译文要连模型
- **现象**：引导第 3 步写着"示例不连模型也能看完整效果"。进阅读器点「译文」，提示"要连接模型才能生成译文"，而且按钮还是高亮的选中态。点「释义」只是行距变大，看不到任何释义，也没有提示。（图 04）
- **建议**：示例文章把译文和语境释义也预先生成好（总结已经预生成了，补齐就行）；做不到就改文案，写成"总结和查词不用模型"。功能没生效时按钮不要停在选中态；「释义」没有内容时要提示原因。

#### P1-2 第一次复习就弹"上次复习到一半，还剩 1 张"
- **现象**：新库，第一次点「开始复习」，toast 就说上次复习到一半。（图 10）
- **建议**：只有真的存在没做完的 session 时才提示"继续"；第一次进入不要提示。另外 toast 盖住了底部的快捷键说明。

#### P1-3 生词本表格在 1024 宽度下"释义"列塌成一个字
- **现象**：表头"释义"竖着排成两行，内容只剩 `a…`，生词本的核心信息直接看不到。（图 08）
- **建议**：给释义列 `min-width`，或者让它占满剩下的宽度（`flex:1`）；窄窗口下把"遇见 / 下次复习"收进第二行，或者隐藏。

#### P1-4 订阅文章用 URL 当标题，正文抓错
- **现象**：打开 HN 的 "The Internals of PostgreSQL"，标题变成 `https://www.interdb.jp/pg/index.html`，大号衬线字一行放不下，横向溢出被截断；正文是站点横幅（"\*\* I am officially open to new international opportunities! 🌍"），Markdown 的 `**` 也露出来了。总结显示"上次没有生成成功"。（图 07）
- **建议**：没抓到 `<title>` 时退回订阅条目自带的标题（列表里明明是对的）；标题加 `overflow-wrap:anywhere`；正文提取失败或太短时，标成"只有摘要"，并给一个"在浏览器打开"的入口，不要把横幅当正文；清掉残留的 Markdown 标记。

#### P1-5 统计数据互相矛盾
- **现象**：顶部"阅读 0 分钟 · 0 词"，底部"按类型阅读量：文学 118 词"；学习天数 = 1、复习 1 次，但学习日历上今天那格是空的。（图 11、12）
- **建议**：三处用同一套口径；当天有复习就点亮日历；没数据的图表（已掌握的词、每日阅读）换成空状态说明，不要只画一条横线。

### P2

#### P2-1 小窗口下侧栏和浮层互相遮挡
- 阅读器右侧面板固定宽度，1024 宽时正文只剩一半，浮动工具栏压在正文最后一行上。
- 「回到开头」按钮盖住了 Tibi 面板的输入框和面板底部那行字。（图 03）
- 查词弹窗压在总结面板上，且没有避开右栏。
- **建议**：窗口宽度小于 1200 时，右侧面板改成覆盖式抽屉或默认收起；「回到开头」放到工具栏里；查词弹窗按正文列的边界定位。

#### P2-2 订阅列表重复多、提示吵
- News in Levels 同一篇新闻 level 1 / 2 / 3 各占一行（图 05），30 条 HN、10 条 NIL 一进来侧栏就挂角标 40。
- HN 每条都写"约 6 分钟"，看得出是占位值，点开后又变成"约 5 分钟"。
- The Conversation 源名标红，进去顶部写着 `This operation was aborted`（英文原始报错），下面又是"都看过了"的空状态，两者矛盾。（图 06）
- 点开文章时条目右侧出现"◌ 开始"，"开始"二字让人看不懂。
- **建议**：同一篇文章的多个分级版本合并成一条，默认按用户水平选版本；订阅的未读数不进侧栏角标，或者改成一个小圆点；没算出时长就别显示；失败的源显示中文原因加「重试」，空状态写"还没抓到文章"；加载文案改为"正在打开…"。

#### P2-3 新手引导的细节
- 第 1 步打完中文昵称后，第一次点「继续」没反应（输入法组字刚结束），要点第二次。（自动化输入下复现，真机需复核）
- 第 2 步副标题说"查词、标注和复习不需要模型"，下方表格却写"快速档 · 查词、标注、日常问答 → deepseek-flash"，前后矛盾。（图 01）
- 第 2 步没有「上一步」，第 3 步才有。
- 第 3 步默认自动导入第一篇示例；为了看看再点第二篇，第二篇也被导入了，书架上一下子多出 2 篇。卡片写"约 10 分钟"，阅读器里是"约 11 分钟"。
- 完成态用黑色对勾、当前步骤用蓝色圆点，材料多选 chip 又是黑底，主色不统一。
- **建议**：用 `compositionend` 处理，或在点击时先 blur 再提交；改掉表格里的"查词"；三步都给「上一步」；选卡片只是预览，点「开始阅读」时才导入；chip 选中态统一用主色。

#### P2-4 查词卡和词条信息口径不一
- 查词弹窗显示"zk · gk · 柯林斯 ★★★★★"，生词本详情里同样的数据写成"中考 / 高考 / 牛津 3000"，两处标签不一样，前者是拼音缩写，用户看不懂。（图 02、09）
- 生词本列表"遇见 0"，详情里"遇到过的句子 1"。
- 点一次"认得"，历史记录里出现两条（"→ 生词"、"→ 认得"）。
- "such"这种基础词点一下就进了生词本和今日复习。
- 两个喇叭图标（系统朗读 / AI 朗读）没有文字也没有 tooltip，区分不了。
- **建议**：统一用中文标签；"遇见"和例句数用同一个来源；首次标熟练度只记一条；对四六级以下的高频词，先问一句"加入复习吗？"，或者直接按"已知"处理；两个朗读按钮加 tooltip，或做成一个按钮加下拉。

#### P2-5 ⌘K 搜索结果分两拍出现
- 输入 "gift" 后，"全部"一栏先只有"在词典里查 / 问 Tibi"，书架里的 *The Gift of the Magi* 要过一两秒才出现，切到"文章"才能马上看到。（图 13）
- 搜索里还能搜到一条"讲解 · The Gift of the Magi"的对话：我只是打开过阅读器的 Tibi 面板，一句话都没说，就生成了一条对话记录，而侧栏"最近"里又不显示它。
- **建议**：各类结果出来一类显示一类，先显示的旁边加加载占位；空对话不落库，或者侧栏和搜索用同一套规则。

#### P2-6 设置页
- 左侧目录不跟随滚动：滚到"模型"一节，高亮还停在"通用"。（图 15）
- 系统朗读的下拉里有 Bahh、Bells、Boing、Bubbles、Jester、Organ、Superstar、Trinoids、Wobble、Zarvox 这些整活音色，对学英语没用；"Eddy (英语（英国）)（英音）"重复标注了一遍。
- "权限模式"放在"通用"里，说明有 4 行，挤在很窄的一栏，概念偏工程化。
- "模型"表单是灰底，和其他白卡片风格不同；保存后同时弹出两个 toast。
- **建议**：目录做 scrollspy；音色只保留 en-US / en-GB 下自然的那几个；把"权限模式"放进"高级"，说明压到一行，详情放 tooltip；表单统一用白卡片，两个 toast 合成一个。

#### P2-7 首页的"今天"区块排版
- 待复习、今日阅读、生词本三张卡排成 2 列，第二行右边空出一格。（图 14）
- 生词本卡下面有 7 段进度条，最后一段是蓝色，看不出是什么意思。
- 今日阅读 0 / 20 分钟同时出现在首页卡片、侧栏底部"今天开始"和统计页三处。
- **建议**：改成 3 列，或者把生词本卡并进"待复习"；7 段条加图例，或者换成"生词 → 掌握"的分布；侧栏底部的进度和首页二选一。

## 3. 做得好的地方（建议保留）

- 正文排版：衬线字体、行高、段距都舒服，深色模式下对比度合适。
- 查词卡的"熟练度六档"一键就能标，复习时语境填空直接用原文句子，闭环很顺。
- 词典页：能识别变形（went → go），"在你读过的文章里"会高亮 gone / went / going，体验很好。
- ⌘K 面板的范围切换和键位提示做得完整。
- 复习完成页有数据，也给了下一步（读一篇用到这些词的短文 / 去练习）。

## 4. 建议的修复顺序

1. **先修信任问题**：P1-1 示例的译文和释义、P1-2 假的"继续复习"、P1-5 统计口径、P2-4 熟练度和遇见次数。
2. **再修布局**：P1-3 生词本列宽、P1-4 订阅标题和正文、P2-1 窄窗口下的右侧面板和遮挡。这些可以一次性在 1024 / 1280 / 1440 三档宽度下回归。
3. **然后精简**：P2-2 订阅降噪、P2-7 首页、P3 里的重复入口和内部文案。
4. **最后**：真机补测本次没覆盖的原生部分（窗口外观、托盘、通知、钥匙串、自动更新），同时复核 P2-3 的输入法问题。
